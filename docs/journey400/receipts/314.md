## Behavior and compatibility

- `bracket_precise` queries the existing retained History deque directly. It does not introduce another history container, clock, time origin or session identity. Logical binary search works across wrapped storage in O(log(len)), borrows states, and allocates nothing.
- A query is `(tick: u64, fraction: f64)`. Fraction must be finite and in inclusive `[0, 1]`; negative zero equals zero. Exactly 1 carries to the next integer tick with checked addition. `(u64::MAX, 1)` returns `TickOverflow`; `(u64::MAX, 0.5)` is a valid query after every possible stored integer sample. Invalid values are rejected even for empty/stale history and regardless of endpoint policy.
- Tick identity and all bracketing decisions compare integers without converting absolute ticks to float. An exact retained tick returns only its actual state. An interior query returns its two consecutive retained samples, including sparse gaps. Both subtractions occur on ordered u64 values before conversion, so even the full `0..u64::MAX` gap cannot wrap; adjacent ticks above 2^53 remain distinct.
- Interpolation alpha is f64 computed as `((tick - before_tick) as f64 + fraction) / (after_tick - before_tick) as f64`. Identity is exact, but weights are approximate over wide gaps. An interior query near `u64::MAX` between samples 0 and MAX can round to alpha 1 and still returns `Interpolated`. Consumers must match outcomes rather than infer identity from alpha.
- Endpoint policy is explicit. `Reject` (the policy type's default) reports `BeforeOldest`/`AfterNewest`; it does not select or extrapolate a state. `Clamp` returns the nearest actual endpoint as `Clamped`. An exact endpoint remains `Exact` under either policy. Empty history remains `Empty`.
- Freshness is supplied separately as `minimum_newest_tick: Option<u64>`, an inclusive lower bound on the newest retained authority tick. `None` disables the check. If the newest tick is strictly lower, `Stale` reports that sample and the cutoff. A host may derive the cutoff from explicit same-session `now_tick.saturating_sub(max_age_ticks)`. The requested presentation tick is never interpreted as now. This only checks newest-history freshness at integer resolution; it neither rejects every individually old sample nor imposes a maximum interpolation gap.
- Outcome precedence: invalid fraction/overflow, empty, stale, then exact/interpolated/range. Freshness equality passes. Neither clamping nor an exact old query overrides stale history. A future or past query alone does not establish staleness.
- `clear` destructively drops retained states and forgets the monotonic insertion watermark while retaining the allocated deque storage and configured capacity. Lower ticks can start the next epoch; repeated clear is safe. Caller state destructors may allocate or panic; no rollback or recovery of dropped samples is promised. Successful nonallocating-state clear/refill is allocation-free on the tested host.
- Every existing History signature, struct layout, capacity policy, insertion/drop policy and legacy `bracket(f64)` implementation is unchanged. Capacity 0 and above 4096 still panic; accepted inserts remain strictly increasing, reject duplicates/decreases before eviction, and evict only the oldest at capacity. u64 tick wrap requires explicit reset. Legacy bracket still rejects old/future/nonfinite targets and retains its original f64 precision limits/f32 alpha.
- The entire ClockSync implementation and original inline tests were checked byte-for-byte against HEAD and are unchanged, including 1/8 smoothing and out-of-range rejection. New APIs impose no Clone bound on retained states. New enums are non-exhaustive; old public construction/exhaustiveness is unaffected. No wire/save/replay/native/Wasm export changes.

## Exact public additions

All paths below are under the already public `ferravex_net::history` module. API signatures/variants (not a standalone example):

```text
impl<T> History<T> {
    pub fn bracket_precise(
        &self,
        tick: u64,
        fraction: f64,
        endpoints: HistoryEndpointPolicy,
        minimum_newest_tick: Option<u64>,
    ) -> Result<HistoryBracket<'_, T>, HistoryQueryError>;
    pub fn clear(&mut self);
}

#[non_exhaustive]
pub enum HistoryEndpointPolicy { Reject, Clamp }

#[non_exhaustive]
pub enum HistoryBracket<'a, T> {
    Empty,
    Exact { sample: (u64, &'a T) },
    Interpolated {
        before: (u64, &'a T),
        after: (u64, &'a T),
        alpha: f64,
    },
    BeforeOldest { oldest: (u64, &'a T) },
    AfterNewest { newest: (u64, &'a T) },
    Clamped { sample: (u64, &'a T) },
    Stale { newest: (u64, &'a T), minimum_newest_tick: u64 },
}

#[non_exhaustive]
pub enum HistoryQueryError { InvalidFraction, TickOverflow }
```

`HistoryEndpointPolicy`: Clone, Copy, Debug, Default (Reject), PartialEq, Eq.
`HistoryBracket`: Debug, PartialEq (derived bounds on T). States need not implement those traits merely to query/match them.
`HistoryQueryError`: Clone, Copy, Debug, PartialEq, Eq, Display, std::error::Error.
