## Behavior and compatibility

- `World::query_filtered<Q, F>` and `try_query_filtered<Q, F>` compose fetched
  accesses with a separate sealed structural filter. `With<T>` tests presence;
  `Without<T>` tests absence. They inspect existing storage through `World::has`
  and never borrow component values or register missing storage.
- Tuple filters are conjunctions. `All<(...)>` is explicit conjunction,
  `Any<(...)>` is disjunction, and `Not<F>` negates within live entities.
  Empty `()` and `All<()>` accept all live entities; `Any<()>` accepts none.
  Repeated and contradictory predicates are valid logical expressions.
- Each tuple/All/Any group accepts zero through four clauses. Groups may nest;
  each expression's total size/depth is fixed by its concrete Rust type, with
  no runtime tree, dynamic clauses, heap storage, or separate runtime capacity
  error. There is no additional global expression-depth ceiling. A compile-fail
  doctest verifies that a five-clause group is rejected.
- Query alias checks still inspect fetched `Q` only and run before scanning,
  even on an empty world or an always-false filter. A mutable fetch and a
  presence predicate for the same component are allowed. Repeating a mutable
  fetched access, including optional access, remains `Error::ConflictingQuery`.
- The existing iterator now checks live identity, `F`, and all required `Q`
  matches before fetching any component. Excluded entities cannot produce
  irrelevant borrow errors. Markers may be mutably borrowed elsewhere without
  interfering with structural tests. If that marker is also fetched, normal
  runtime borrowing still applies; presence never masks a fetched borrow error.
- Stable slot order, dead-slot exclusion, reused-slot generations, fallible
  iteration continuing after errors, partial tuple cleanup, panic behavior,
  retained guard lifetimes, iterator size hints, and fused exhaustion remain.
  Removing/reinserting components, despawning/reusing slots, emptying the world,
  and repopulating it require no filter reset or cached-membership invalidation.
- Existing `query`, `try_query`, `get`, and `get_many` public signatures remain.
  Existing query/iterator type annotations keep working through a default `F=()`
  parameter. No public enum variants, struct-literal construction, entity
  provenance rules, wire/save/replay formats, native/Wasm exports, tuple-fetch
  ceiling, or dependencies change. The private standard-library `Any` import
  was renamed `StdAny` to make room for the public disjunction type.
- `tags::TagPredicate` is untouched: it filters tag values in the engine rather
  than ECS component presence. Simulation has no rendering, clock, or I/O coupling.

## Exact public API

Signature excerpts (opaque structs retain private fields):

```rust
pub trait QueryFilter: sealed::QueryFilter {
    #[doc(hidden)]
    fn matches(world: &World, entity: Entity) -> bool;
}
pub struct With<T: 'static>(/* private */);
pub struct Without<T: 'static>(/* private */);
pub struct All<F>(/* private */);
pub struct Any<F>(/* private */);
pub struct Not<F: QueryFilter>(/* private */);

impl World {
    pub fn query_filtered<Q: Query, F: QueryFilter>(&self) -> QueryBorrow<'_, Q, F>;
    pub fn try_query_filtered<Q: Query, F: QueryFilter>(
        &self,
    ) -> Result<QueryBorrow<'_, Q, F>, Error>;
}

pub struct QueryBorrow<'world, Q: Query, F: QueryFilter = ()> { /* private */ }
pub struct QueryIter<'world, Q: Query, F: QueryFilter = ()> { /* private */ }
pub struct TryQueryIter<'world, Q: Query, F: QueryFilter = ()> { /* private */ }

impl<'world, Q: Query, F: QueryFilter> QueryBorrow<'world, Q, F> {
    pub fn iter(&self) -> QueryIter<'world, Q, F>;
    pub fn try_iter(&self) -> TryQueryIter<'world, Q, F>;
}
```

`QueryFilter` is implemented for `With<T>`, `Without<T>`, `Not<F>`, `()`,
`All<()>`, `Any<()>`, and tuples of one through four `QueryFilter` types, plus
`All<Tuple>`/`Any<Tuple>` for those tuple arities. Filters are used as type
arguments and require no value construction. External implementations are sealed.

`QueryIter<'world,Q,F>` implements `Iterator<Item=Q::Item<'world>>` and
`FusedIterator`; `TryQueryIter` implements
`Iterator<Item=Result<Q::Item<'world>,Error>>` and `FusedIterator`.
`IntoIterator` for owned, shared, and mutable `QueryBorrow<'world,Q,F>` all
return `QueryIter<'world,Q,F>` with `Q::Item<'world>` items.
