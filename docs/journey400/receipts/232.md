## Exact router semantics and bounds

- Explicit 2..=64 distinct peer IDs (zero is legal), nonzero host-provided link namespace, private generation initially1. The host must keep namespaces distinct across independently live routers and never reuse one while older handles may survive. Handles are local routing guards, not authentication. No global ID counter, socket, thread, entropy or wall clock exists.
- Aggregate packet cap 0..=4096; aggregate payload-byte cap 0..=4915200, independently configured. Datagrams must have 1..=1200 bytes (`MAX_PACKET_BYTES`); same-endpoint sends reject. Bytes are opaque: malformed protocol bytes pass local admission and are rejected by the actual codec/driver later. No wire/save/replay format changed.
- Construction uses fallible exact reservation for the bounded peer and packet vectors. Each retained packet stores a fully initialized [u8;1200] array, metadata and its original complete prefix. Send copies the bytes; later caller mutations cannot alter the retained packet. No send/receive/reset/reset_endpoint/dispose operation allocates or grows storage. Physical storage includes array tails, metadata, padding and allocator overhead; the byte budget counts payload prefixes only. This is a source-level allocation policy, not allocator/RSS measurement. AllocationFailed is explicit; actual allocator exhaustion was not injected.
- One shared monotonic exact-microsecond Duration domain, inclusive 0..=2^53us. Equal times allowed; sub-microsecond, backwards or above-domain input rejects. Every successful time-bearing operation, including receive returning None, advances the watermark. On an existing router every returned error leaves time, queues, ordinal, generations and output unchanged. Failed operations cannot reserve capacity or consume impairment ordinals.
- Every locally accepted packet gets the next nonwrapping one-based global admission ordinal, across all routes. Periods Some(0) reject. Every Nth admission can be marked lost and/or receive extra reorder delay; selections may overlap. Common delay and extra delay are independently exact-microsecond 0..=60s. Due-time overflow rejects before admission. Default delivery is simple reliable FIFO; impaired delivery is minimum `(due_at, ordinal)` per destination, with exact FIFO ties and no head-of-line blocking across destinations.
- `send` success ALWAYS means complete bounded local admission, including packets marked for later loss. Full packet/byte capacity refuses even a packet selected for loss. Only that complete-admission result is returned to driver callbacks. Network impairment happens afterward; no fake ACK or remote-delivery success is synthesized.
- A receive scans at most4096 slots, removes at most one due packet/loss and moves at most one slot with swap_remove. Endpoint lookup is at most64 peers. There is no retry-until-success/random loop. Host iteration budgets are explicit. Loss records retain full packet/byte capacity until received for that destination; poll every live destination. No background cleanup occurs.
- Short output rejects even a selected loss record before dequeue. Ordinary success writes only output[..len]; caller tail remains unchanged. None/lost output writes nothing; `lost=true` must never be passed to a driver. Receive reports original identities, lengths, supplied admission/due times and ordinal.
- Endpoint reset removes both traffic directions for that endpoint, increments its generation and preserves other peers, global ordinal and time. Whole reset clears traffic, resets the impairment ordinal and increments every live generation, preserving config, disposed state and time. Neither reset rewinds time. Dispose permanently removes one endpoint and all its traffic; repeated/stale operations reject. Drop disposes all storage. Generation/ordinal exhaustion never wraps; preflight retains old traffic/state. Recreate a router with a fresh namespace for a new lifetime.

## Inspector scheduling and accepted feedback

One real ServerState plus two separately instantiated ClientStates route complete original datagrams through one production LocalLink; two simultaneous independent LocalSessions are validated. SocketAddr is only the host's stable peer-key mapping; no socket is created. Callback output uses exact initialized prefixes and returns true only for successful LocalLink admission, preserving driver retry timestamps on queue refusal.

The host accumulates integer microseconds at exactly64Hz. A frame issues at most4 actual authority ticks, records issued/executed separately, and gives each catch-up tick its own exact15625us boundary before advancing to frame end. Excessive elapsed time/domain overflow rejects before mutation. It does not silently discard authoritative work. Runtime driver/transport errors terminate the inspector with committed driver effects intact; this example provides no rollback/retry of a failed frame.

Each core call has an8-datagram/9600-byte output budget. Each pump has4 passes *3 destinations *16 removals = at most192 ingress/loss records. A frame uses at most14 pumps (2688 removals), bounded polling and at most4 server/8 client tick calls. Router default storage is128 packets/153600 bytes. Per-frame feedback vectors collect bounded driver drains (at most6 drains *512 events/client) and at most4 TickOutputs, then are dropped; no unbounded lifetime trace is retained. The cores retain their own frozen231 bounds/allocation policies; the whole inspector is not allocation-free.

Poll/receive run on zero-tick and menu frames. Menu masks local commands/retains aim while authority ticks and protocol work continue. Inputs in this inspector are explicitly scripted held levels; there is no host gameplay-edge queue consumed prematurely or repeated as a pressed edge. An interactive consumer should consume latched gameplay edges inside actual tick calls only. Shutdown intentionally stops issuing game ticks while supplied-time protocol maintenance continues for128 frames/one second; this is distinct from a menu.

Printed authority feedback comes from accepted TickOutput.events; client feedback comes from actual validated/drained NetworkEvents. Samples use local_player() and rendered_players(now), not private memory or a separate predictor. Final snapshot can legitimately lag the last authority tick because snapshots are periodic; shutdown polling does not fabricate another authority tick/snapshot.
