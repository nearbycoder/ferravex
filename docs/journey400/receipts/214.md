## Concrete behavior and compatibility

The API intentionally has two phases:

1. `World::plan_duplication` uses `&World` to capture a fixed array of selected
   owned component tuples. It validates duplicate types even for N=0, all source
   identities in order, duplicate source identities, then reads in source/tuple
   order. Every read guard is acquired before the first component Clone call.
   Missing components and incompatible mutable guards return errors and release
   completed/partial guards. These reported errors call no Clone, spawn nothing
   and change no ECS storage, components, free slots or identities.
2. The returned plan owns the captured bundles without borrowing the source
   world. Its consuming `try_spawn` reuses the existing `World::try_spawn_batch`.
   Successful admission returns exactly N `(old, new)` pairs in source order.
   A reported SpawnError returns the entire owned plan without dropping or
   recloning components, spawning a prefix or consuming a free-slot prefix.
   Callers can prepare more capacity and retry or explicitly discard the plan.

Selections are `()` or tuples of one through eight explicitly named stored
`Clone + 'static` component types. Non-Clone transient components remain legal
in normal bundles and are omitted unless selected (selection then fails to
compile). No reflection, serializer, global registry scan, whole-World clone,
hierarchy traversal or second hierarchy is introduced. Repeated sources are
rejected so the fixed old-to-new array has unique source keys. Its size is exactly
the caller's compile-time N; no output overflow or scratch heap collection is
needed. Small arrays are intended for authoring; stack use scales with N and B.

Identity is allocated by the existing generational spawn path, not copied from
the source. Explicitly stored Entity components and embedded Entity references
are ordinary cloned values; there is no implicit remap. Query Entity access is
not used to clone identity. Shared selected guards and mutable unselected guards
are permitted during capture. Structural spawning still requires exclusive world
access after guards have been released.

Capture is a snapshot, not a deferred read. Source mutation, component removal,
despawn or replacement does not trigger rereading at spawn. Component Clone
semantics govern shared internals; an Rc/RefCell component is not promised a deep
copy. Old handles in the map are informational and may already be stale. A plan
may intentionally spawn into a different world, including after the source world
is dropped. Old/new handle bits may then match across the two worlds. Existing
world-local handle provenance limits remain; a foreign matching identity cannot
be detected.

Prepared sparse-index budgets, selected LIFO free-slot ordering, generation
retirement, independent component preparation, no growth of prepared ECS buffers
on accepted batches and ownership return on reported batch errors are unchanged.
Clone allocation/effects happen during capture, before later spawn admission;
capacity failure is not a rollback of those earlier Clone calls. No combined
capacity-before-Clone transaction is promised.

The capture algorithm uses bounded arrays and existing borrow guards with no ECS
metadata heap allocation. User Clone can allocate, mutate shared interior state
or panic. Earlier clones/read guards unwind normally, but user Clone/Drop and
allocator panics/aborts are not caught or rolled back. A user Drop panic during
unwind can abort. No rollback of user effects or general allocation-free Clone
claim is made. Discarding a returned plan runs its component destructors.

Existing Error and SpawnError variants/signatures are untouched, as are World
defaults, Bundle/Access/Query contracts, optional/filter aliases, normal growing
spawn/insert, identity bit layout, wire/save/replay/native/Wasm exports, and feature
boundaries. Simulation gains no render, time, input or platform I/O dependency.

## Exact public API

Signature excerpts, not standalone runnable snippets:

```rust
#[derive(Clone, Debug, PartialEq, Eq)]
#[non_exhaustive]
pub enum DuplicationError {
    Access(Error),
    DuplicateSource(Entity),
}

#[derive(Debug)]
#[must_use]
pub struct DuplicationPlan<B: CloneBundle, const N: usize> { /* private fields */ }

impl World {
    pub fn plan_duplication<B: CloneBundle, const N: usize>(
        &self,
        sources: [Entity; N],
    ) -> Result<DuplicationPlan<B, N>, DuplicationError>;
}

impl<B: CloneBundle, const N: usize> DuplicationPlan<B, N> {
    pub fn try_spawn(
        self,
        world: &mut World,
    ) -> Result<[(Entity, Entity); N], (SpawnError, Self)>;
}

pub trait CloneBundle: Bundle + sealed::CloneBundle {
    #[doc(hidden)]
    type Borrowed<'world>;
    #[doc(hidden)]
    fn borrow(world: &World, entity: Entity) -> Result<Self::Borrowed<'_>, Error>;
    #[doc(hidden)]
    fn clone_components(components: &Self::Borrowed<'_>) -> Self;
}
```

DuplicationError implements Display and std::error::Error; `source()` exposes the
wrapped Error for Access and returns None for DuplicateSource. The new enum is
non-exhaustive; existing exhaustive enums have not gained variants. Plan Debug
is conditional on B: Debug and is not required by capture/spawn. CloneBundle and
its sealed marker are implemented only for `()` and existing bundle tuples of
one through eight Clone + 'static types. Borrowed is `()` or the corresponding
tuple of shared Ref guards. No public existing struct literal gains fields.
