## Concrete behavior

Items supply finite, ordered `minimum <= preferred <= maximum` widths and a
nonnegative grow weight. Zero opts out of growth. Fixed-width items have all
three extents equal. Row height is authored, positive and constant; the helper
does not measure/scale fonts or clip widgets into partial-height rows.

Rows greedily admit consecutive items by **minimum** widths plus horizontal
gaps. Exact equality fits. Space above minima is distributed in proportion to
each preferred-minus-minimum deficit, allowing a fixed icon alongside a shrinking
long label. Only after every preferred width fits do positive grow weights divide
surplus, redistributing capped shares to remaining items. Last rows use this same
policy, so a lone growing item can widen, while fixed/zero-weight items leave
right-side slack. Wrapping is explicit; disabling it emits only the first row.
No leading/trailing gap or justification is added.

Output is always a stable **prefix**, with `output[i]` corresponding to `items[i]`.
A too-wide minimum, exhausted height, or disabled wrap stops placement without
skipping a large action in favor of a smaller later action. A short caller buffer
returns the same geometric prefix as a full buffer; it does not alter row sizing.
`overflow = items.len() - written` includes both insufficient space and output
truncation. `rows` counts rows represented in the written prefix. All input items
are validated, and all fitting rows calculated even with an empty output buffer.

At most 256 items are accepted; excess input returns `Capacity` before inspecting
its values. The production function uses fixed stack arrays (256 rectangles,
256 f64 widths and 256 f32 limits; 7 KiB array payload total), no retained tree,
heap allocations or platform/clock/input dependencies. Weighted saturation has
at most one pass per row item: O(n²) worst-case work, O(256) scratch. Output length
does not cause extra scanning; only its written prefix is copied.

All errors leave the entire output unchanged. Successful calls leave the unwritten
tail unchanged too: only `output[..report.written]` is current. Empty input returns
zero counts; an empty parent returns every item as overflow. Zero-width items are
inert and still occupy a source index/gap. There is no retained state to reset;
reusing the buffer with a new report and rebuilding `UiState` removes stale widgets,
focus and capture. Do not submit the old tail after resize or a failed calculation.

Widths, deficits, sums and weighted shares use f64 intermediates, including huge
finite gaps/weights. Final widths round down but never below a declared minimum
or above a maximum. Origins round upward after the previous f32 edge plus gap;
backward inward reservation protects later minima. Returned rectangles are valid,
nonnegative, disjoint and contained under `Rect`'s f32 half-open endpoint rules.
Rounding can leave slack/reduce preferred width. A finite request that cannot be
represented under this policy without breaking a minimum or losing a positive
edge returns `Unrepresentable` atomically, even after earlier rows were computed.
This is conservative finite-f32 layout, not an arbitrary-precision packing solver.

The parent coordinate space is preserved. Task 271 rectangles already include
safe-area offsets and use absolute logical pixels. Feed them directly to flow and
draw with zero-inset responsive UI; do not apply safe insets or DPR a second time.
Use returned rectangles unchanged for paint, pointer hits and directional focus.

## Exact public API

The following are signatures, not a runnable snippet. All live in
`ferravex_play::ui::flow`.

```rust
pub const FLOW_ITEM_CAPACITY: usize = 256;
pub struct FlowItem {
    pub minimum: f32,
    pub preferred: f32,
    pub maximum: f32,
    pub grow: f32,
}
impl FlowItem {
    pub const fn fixed(width: f32) -> Self;
}
pub struct FlowOptions {
    pub row_height: f32,
    pub gap: [f32; 2], // horizontal, vertical
    pub wrap: bool,
}
// Default: row_height 44, gap [8, 8], wrap true.
pub struct FlowReport {
    pub written: usize,
    pub overflow: usize,
    pub rows: usize,
}
pub enum FlowError {
    Capacity,
    InvalidLayout,
    InvalidItem { index: usize },
    Unrepresentable,
}
pub fn layout(
    parent: ferravex_play::ui::Rect,
    items: &[FlowItem],
    options: FlowOptions,
    output: &mut [ferravex_play::ui::Rect],
) -> Result<FlowReport, FlowError>;
```

All public types are `Clone + Copy + Debug + PartialEq`; report/error also `Eq`;
options/report implement `Default`; error implements `Display + std::error::Error`.

## Consumer handoff

Current Orchard `examples/orchard-guard/src/lib.rs` manually places upgrade at
`(240,683,415,55)`, buy controls at widths 190, and pause/restart at widths 110.
Its existing `button` wrapper already calls `Ui::hud_button`. Its owner can replace
only the action rectangle calculation with flow, retaining authored 55-unit row
height, enabled/availability rules, stable action IDs and actual remapped hints.
Use fixed extents for short actions, measured preferred extents for price/upgrade
labels, and an explicit compact/secondary-action policy when `overflow != 0`.
Use the displayed prefix for both button submission and input. Do not change the
game's authored world framing or make an omitted essential action inaccessible.

Physics 2D currently computes seven action rectangles with 4/7 equal columns;
Physics 3D `footer_layout` computes eight controls with 4/8 equal columns. Their
owners can replace that rectangle calculation with content policies, preserving
shape selection, paused editor/step behavior and the same visible/click geometry.
The existing 36-unit button height is a game policy; the flow default is 44 and
adopting a larger touch target requires deliberately reserving sufficient space.
Equal cards should continue to use `hud_slots` when mixed extents add no value.

The recipe below is the executable handoff: actual renderer `Ui::hud_button` and
`Ui::paint`, fixed 18-unit text, first-party font measurements, 271 safe rectangles,
and a matching `UiState` checking stable IDs/hit/focus against those exact rects.
The default run is headless: it exercises the renderer's CPU command/paint path,
not GPU presentation or browser input. `--window` is an optional compiled native
viewer for parent visual checking (not executed by the recipe runner). It retains
the renderer's own input handling. The mirror `UiState` is only headless geometry
verification, not a replacement game input path.

## Runnable fixed-size action-label recipe

```rust,check crate-type=bin
use ferravex_play::ui::{
    FocusDirection, FocusWrap, HudEdge, HudRegions, Rect, UiState, Viewport, Widget,
};
use ferravex_play::ui::flow::{layout, FlowItem, FlowOptions, FlowReport};
use ferravex_render::{self as render, ui::{ButtonStyle, Ui}};

const LABELS: [&str; 4] = [
    "+", "UPGRADE / LONG RANGE FROST TOWER", "DROP SELECTED SHAPE", "STEP",
];
const EMPTY: Rect = Rect { min: [0.; 2], size: [0.; 2] };

fn submit(
    screen: [f32; 2], ui: &mut Ui, state: &mut UiState,
) -> (FlowReport, [Rect; 4]) {
    let viewport = Viewport::responsive(screen, [0.; 4]).unwrap();
    ui.begin(viewport); // Absolute rectangles already include the safe offsets.
    state.begin_frame();
    let mut rects = [EMPTY; 4];
    // A tiny window has no usable action strip. Rebuild both inputs empty.
    let Some(area) = HudRegions::new(screen, [8., 24., 8., 16.], [0.; 2]).ok()
        .and_then(|mut hud| hud.reserve("actions", HudEdge::Top, 148.).ok())
    else {
        state.end_frame();
        return (FlowReport { written: 0, overflow: 4, rows: 0 }, rects);
    };
    let style = ButtonStyle { size: 18., ..ButtonStyle::default() };
    let font = render::get_default_font().try_metrics(18, 1.).unwrap();
    let mut items = [FlowItem::fixed(44.); 4];
    for (index, minimum) in [(1, 132_f32), (2, 120_f32)] {
        let preferred = (font.measure_line(LABELS[index]).unwrap().width + 16.).max(minimum);
        items[index] = FlowItem { minimum, preferred, maximum: preferred + 120.,
                                  grow: if index == 1 { 1. } else { 0. } };
    }
    items[3] = FlowItem::fixed(72.);
    let report = layout(area, &items, FlowOptions::default(), &mut rects).unwrap();
    for (index, &rect) in rects[..report.written].iter().enumerate() {
        let id = index as u64 + 1; // Stable semantic ID, unchanged on wrap/resize.
        ui.hud_button(id, rect, LABELS[index], true, style).unwrap();
        state.add(Widget { id, rect, clip: Some(area), enabled: true, focusable: true }).unwrap();
        let label = ferravex_play::ui::fit_label(
            LABELS[index], rect.size[0] - 16., font.glyph_advance(),
        ).unwrap();
        assert!(label.width <= rect.size[0] - 16.);
        assert_eq!(style.size, 18.); // Truncate with ellipsis, never reduce size.
    }
    state.end_frame();
    (report, rects)
}

fn main() {
    let mut ui = Ui::new();
    let mut state = UiState::with_capacity(4);
    for screen in [[640., 320.], [390., 844.], [2560., 720.], [176., 240.]] {
        render::clear_background(render::BLACK);
        let (report, rects) = submit(screen, &mut ui, &mut state);
        assert_eq!(report.written + report.overflow, LABELS.len());
        for (index, &rect) in rects[..report.written].iter().enumerate() {
            let center = [rect.min[0] + rect.size[0] / 2., rect.min[1] + 22.];
            assert_eq!(state.hit_test(center), Some(index as u64 + 1));
            assert_eq!(state.pointer_down(center), Some(index as u64 + 1));
            assert_eq!(state.pointer_up(center), Some(index as u64 + 1));
            assert_eq!(state.activate_focused(), Some(index as u64 + 1));
        }
        state.pointer_down([10., 30.]);
        if screen[0] >= 390. {
            assert_eq!(state.focus_direction(FocusDirection::Right, FocusWrap::Clamp), Some(2));
        } else {
            assert_eq!(state.focus_direction(FocusDirection::Down, FocusWrap::Clamp), Some(2));
            assert_eq!((report.written, report.overflow), (3, 1));
        }
        ui.finish(true);
        ui.paint(); // Executes CPU paint; this default mode creates no window.
    }
    state.pointer_down([10., 30.]);
    let (report, _) = submit([0.; 2], &mut ui, &mut state);
    assert_eq!((report.written, report.overflow), (0, 4));
    assert_eq!((state.focused(), state.captured()), (None, None));

    if std::env::args().any(|arg| arg == "--window") {
        render::run(render::Conf {
            window_title: "Content-sized action rows / 18-unit labels".into(),
            window_width: 640, window_height: 320, ..render::Conf::default()
        }, async move {
            loop {
                render::clear_background(render::BLACK);
                submit([render::screen_width(), render::screen_height()], &mut ui, &mut state);
                ui.finish(true);
                ui.paint();
                render::next_frame().await;
            }
        });
    }
}
```
