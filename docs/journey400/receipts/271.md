## Behavior and compatibility

`HudRegions` stores eight named strips in a fixed inline array; all production
operations are allocation-free. Names are borrowed `&'static str`, so no per-frame
string storage grows. Duplicate names and the ninth reservation are explicit
errors. Zero-thickness reservations are inert and still occupy a slot. `clear`
reuses storage, forgets names and restores the original safe area/minimum policy.
Reconstruction with `new` resets layout on resize without retaining old origins.

Reservations carve the current remaining rectangle in call order. Top/bottom
consume height; left/right consume width. Earlier strips own corners; repeated
edges stack inward. Failed operations preserve all prior geometry and names.
Caller-authored minimum content dimensions cannot be consumed by reservations.
Insufficient space is an error, never an implicit font reduction or secondary-row
clipping. Fractional split extents round inward to prevent overlap; a positive
strip too small to move its edge in f32 is explicitly rejected.

Geometry uses absolute host logical screen pixels, including safe-area offsets.
Insets follow the existing `Viewport::responsive` left/top/right/bottom order and
proportional collapse. Use a **zero-inset** responsive HUD viewport to draw these
absolute rectangles, with the same rectangles for widgets/touch hit targets.
Fonts remain at the caller's authored screen size. Do not apply DPR or safe
insets twice.

`fit_canvas` aspect-fits only the world and returns the existing `Viewport` type
for displayed bounds and half-open pointer mapping. A content dimension below
one logical pixel returns `Ok(None)`; invalid design/transform values return an
error. Fit data includes the full screen size and normalized camera translation.
The current `Canvas2D::camera()` ignores asymmetric `Canvas2D.offset` when it
centers the world: the recipe sets `Camera2D.offset` explicitly, so drawing and
pointer mapping agree. Use the returned viewport's `unproject` at shared HUD
edges: the preexisting `Canvas2D::pointer` includes its right/bottom boundaries.
No existing `Rect`, `Viewport`, `UiError`, `Canvas2D`, camera, wire/save/replay,
export or feature behavior was changed. This helper does not add a scissor or
clip out-of-world draw calls.

## Runnable renderer adapter and camera/input check

This complete first-party headless recipe adapts an existing canvas value. It
uses the real renderer `Camera::matrix`, tests short landscape/portrait/ultrawide,
asymmetric safe areas, shared hit geometry, full-content boundary ownership,
zero-size suspension and synthetic framebuffer conversion at DPR 1/2/3. It does
not create a window, render pixels, or test a physical display/device.

```rust,check crate-type=bin
use ferravex_play::ui::{HudEdge, HudLayoutError, HudRegions, Viewport};
use ferravex_render::{Camera, Camera2D, Vec2, canvas::Canvas2D, vec2};

pub fn fit_hud_canvas(
    canvas: Canvas2D,
    hud: &HudRegions,
) -> Result<Option<(Canvas2D, Camera2D)>, HudLayoutError> {
    let Some(fit) = hud.fit_canvas(canvas.size.to_array())? else {
        return Ok(None);
    };
    let viewport = fit.viewport();
    let canvas = Canvas2D {
        screen: Vec2::from(fit.screen()),
        scale: viewport.scale(),
        offset: Vec2::from(viewport.pixels().min),
        ..canvas
    };
    let mut camera = canvas.camera();
    camera.offset = Vec2::from(fit.camera_offset());
    Ok(Some((canvas, camera)))
}

fn main() -> Result<(), HudLayoutError> {
    for screen in [[640., 320.], [390., 844.], [2560., 720.]] {
        let mut hud = HudRegions::new(screen, [8., 24., 12., 16.], [160., 100.])?;
        let header = hud.reserve("header", HudEdge::Top, 76.)?;
        let actions = hud.reserve("actions", HudEdge::Bottom, 44.)?;
        let footer = hud.reserve("footer", HudEdge::Bottom, 40.)?;
        let original = Canvas2D::fit(vec2(1280., 720.), Vec2::from(screen));
        let (canvas, camera) = fit_hud_canvas(original, &hud)?.unwrap();
        let viewport = hud.fit_canvas(canvas.size.to_array())?.unwrap().viewport();
        let matrix = camera.matrix(screen[0], screen[1]);
        for point in [vec2(0., 0.), vec2(640., 360.), vec2(1200., 700.)] {
            let logical = canvas.project(point);
            assert!(canvas.unproject(logical).distance(point) < 0.001);
            let hit = viewport.unproject(logical.to_array()).unwrap();
            assert!(Vec2::from(hit).distance(point) < 0.001);
            let ndc = matrix.project_point3(point.extend(0.));
            for dpr in [1., 2., 3.] {
                let framebuffer = vec2(
                    (ndc.x + 1.) * screen[0] * dpr * 0.5,
                    (1. - ndc.y) * screen[1] * dpr * 0.5,
                );
                assert!((framebuffer / dpr).distance(logical) < 0.001);
            }
        }
        // Both the visible HUD and input use these absolute screen rectangles.
        let ui = Viewport::responsive(screen, [0.; 4]).unwrap();
        assert_eq!(ui.scale(), 1.);
        for region in [header, actions, footer] {
            let center = Vec2::from(region.min) + Vec2::from(region.size) * 0.5;
            assert!(region.contains(ui.unproject(center.to_array()).unwrap()));
            assert!(viewport.unproject(center.to_array()).is_none());
        }
        assert_eq!(header.size[1], 76.);
        assert_eq!(actions.size[1], 44.);
        assert_eq!(footer.size[1], 40.);
        assert_eq!(canvas.size, original.size);
        // A layout resize to zero does not call Canvas2D::fit with zero sizes.
        let hidden = HudRegions::new([0.; 2], [0.; 4], [0.; 2])?;
        assert!(fit_hud_canvas(canvas, &hidden)?.is_none());
    }
    let mut hud = HudRegions::new([800., 600.], [10., 20., 30., 40.], [0.; 2])?;
    let footer = hud.reserve("footer", HudEdge::Bottom, 40.)?;
    let original = Canvas2D::fit(vec2(100., 100.), vec2(800., 600.));
    let (canvas, _) = fit_hud_canvas(original, &hud)?.unwrap();
    let viewport = hud.fit_canvas([100.; 2])?.unwrap().viewport();
    let edge = canvas.project(vec2(50., 100.));
    assert!(footer.contains(edge.to_array()));
    assert!(viewport.unproject(edge.to_array()).is_none());
    assert!(canvas.pointer(edge).is_some()); // Preserved legacy inclusive edge.
    Ok(())
}
```
