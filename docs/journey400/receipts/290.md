# Journey400 task 290 — shared UI type and contrast themes

Implemented and returned for parent integration; this does not change task status
or establish combined native/Wasm/browser integration.

## Owned paths and behavior

- `crates/ferravex-play/src/ui/theme.rs`: registered renderer-independent,
  caller-owned theme tokens, explicit Normal/HighContrast presets, validated
  logical-pixel metrics, complete authored sRGB palettes, atomic bounded palette
  overrides, color contrast measurements and static non-color state guidance.
- `crates/ferravex-play/tests/journey400_290.rs`: ten public behavioral tests,
  including native allocation instrumentation.
- `target/journey-400/receipts/290.md`: this handoff and executable consumer recipe.

No other source/manifests/lockfiles/registrations were edited. The parent-supplied
`pub mod theme;` in `crates/ferravex-play/src/ui.rs` is present and exercised by
public tests/doctests. **No additional root registration/reexport or dependency
change is required.** Public path: `ferravex_play::ui::theme` (the existing facade
can access it through `ferravex::play::ui::theme`). The facade was not built here.

Both presets explicitly choose label/body/heading 16/18/24 logical pixels,
inset/gap/compact gap 16/12/8, control minimum height 44 and stroke 2. All type
sizes must be finite, ordered label <= body <= heading, and in 16..=256. Explicit
scaling accepts finite factors >=1 and rejects values beyond the cap. It never
clamps, truncates, shrinks text to fit or modifies world scale. Gap/inset bounds
are 0..=4096, stroke 1..=64, control height 44..=4096 and at least body plus twice
the compact gap. These are layout requests, not measurements of arbitrary copy.
Reflow, wrapping, scroll/overflow fallback and shared painted/hit geometry remain
consumer responsibilities. Use responsive safe-area viewports for pixel-sized UI;
a caller-selected fitted viewport can still scale logical units.

Palette colors are normalized, unpremultiplied, **opaque sRGB encoded** values.
Canvas and Surface are backgrounds; all other roles are foregrounds on BOTH.
Normal text-role contrast policy is >=4.5:1, HighContrast >=7:1. Focus and Border
are non-text marks requiring >=3:1 and >=4.5:1 respectively. Focus labels must
still use Text/MutedText, not assume an outline color meets small-text policy.
Failed role contrast, invalid/nonfinite/out-of-range channels, alpha, duplicate
roles, capacity or invalid metrics reject before mutating the original theme.
Full related background/foreground batches permit authored light palettes.
Overrides retain the current mode and every untouched token. Empty edits succeed
unchanged; at most eleven distinct color edits are admitted, with capacity checked
before reading entries. Reset is explicit value replacement with a chosen preset
or retained authored theme; there is no retained cache/history/global singleton.

Measurements require explicit `RgbEncoding`: sRGB inputs use the actual math
`Color::try_srgb_to_linear`; already-linear sRGB inputs are not decoded again.
Luminance uses 0.2126 R + 0.7152 G + 0.0722 B in linear light and f64 accumulation;
ratio is (lighter + 0.05)/(darker + 0.05). Math conversion and composited channels
round to f32; results have numerical tolerance, not bitwise portability claims.
Opaque helpers reject alpha !=1. `contrast_on` explicitly decodes all three
inputs, composites background over a supplied opaque backdrop and foreground over
that result in linear light, and measures the two results. Encoded-channel
renderer blending may differ. Premultiplied, HDR/out-of-gamut and unknown-backdrop
inputs are unsupported. Token measurements do not establish physical-display
accessibility, whole-renderer conformance, font legibility or actual device contrast.

State guidance pairs localized descriptive copy with shape/pattern: selected
check/double outline, focus outline/double outline, unavailable cross/hatch,
success check, warning triangle/dots, error octagon/hatch. English labels are
fallbacks; author supplies contextual/localized text and actually draws the cue.
Neutral has no extra cue. These are static; no animation/flash/audio/input or
remapping behavior is added or changed.

## Exact public API

Signatures/definitions below are excerpts, not a separately runnable program.
All new value types are Clone + Copy + Debug + PartialEq; enums except ThemeError
and cue structs StateCue also have Eq. ThemeError implements Display and Error.
Palette/UiTheme fields are private; authoring metrics remain public literals.

```text

pub enum ThemeMode { Normal, HighContrast }
pub enum ColorRole { Canvas, Surface, Text, MutedText, Accent, Success,

pub const COLOR_ROLE_COUNT: usize = 11;

                   encoding: RgbEncoding) -> Result<f64, ThemeError>;

pub struct Palette { /* private fixed [Color; 11] */ }

impl UiTheme {
    pub fn preset(mode: ThemeMode) -> Self;
    pub fn try_new(mode: ThemeMode, types: TypeScale, spacing: Spacing,
                   palette: Palette) -> Result<Self, ThemeError>;
    pub fn mode(self) -> ThemeMode;
    pub fn types(self) -> TypeScale;
    pub fn spacing(self) -> Spacing;
    pub fn palette(self) -> Palette;
    pub fn color(self, role: ColorRole) -> Color;
    pub fn role_contrast(self, a: ColorRole, b: ColorRole) -> Result<f64, ThemeError>;
    pub fn set_colors(&mut self, edits: &[(ColorRole, Color)]) -> Result<(), ThemeError>;
    pub fn set_metrics(&mut self, types: TypeScale, spacing: Spacing) -> Result<(), ThemeError>;
    pub fn text(self, role: TextRole) -> TextTokens;

}
```

## Compatibility and consumer handoff

Existing renderer defaults, UI literal types/exhaustive enums, authored game
palettes, native/Wasm exports and wire/save/replay formats are untouched. There
is deliberately no Default/global theme and no implicit application to any game.
Parent task295 can choose/persist a theme and call `types().try_scaled(...)` plus
`set_metrics`, then rebuild UI layout/hits; this task adds no preference format.
Parent task283 meter and task285 inspector can borrow tokens directly without a
renderer dependency in play, as demonstrated below. Software hosts can consume
the same Color, size, spacing, StateCue and pure Rect values using their existing
painter; no replacement renderer is proposed.

Actual task277 source/receipt were read. `CardLayout::new(bounds, CardContent)`
accepts no theme/style. Its fixed policy is title 24, body/stats/actions 18,
padding 16, section gap 12, action gap 8, action height 44, PANEL and default
TextStyle/ButtonStyle, including fixed stat-list style. It cannot consume these
color/type/spacing choices today. **Do not claim a normal or high-contrast themed
CardLayout merely by passing bounds/content.** Parent/owner may separately add
an additive `CardStyle`/style constructor; no such signature is invented here.
This task does not require that seam to deliver opt-in tokens and an actual
composition recipe. Existing retained ButtonStyle still fixes horizontal text
padding at 8 and focus-border width at 2; the token stroke does not override it.
Selected `button_with_options` has its own existing inversion policy; the recipe
uses ordinary retained buttons only. Text placed on a semantic fill or a custom
selected/disabled fill needs its actual color pair checked independently.

The following complete recipe uses production Ui::compose, measured wrapped
text, StatRowsLayout, a pure-geometry meter, focus outline and disabled button.
It chooses themes explicitly, renders warning text plus visible dot marks and
uses X as a cross cue in contextual disabled copy. It maps tokens only where
current APIs accept them. It tests narrow/wide logical viewports, 1x/1.5x text,
retained paint/inspection geometry, explicit too-short-screen rejection, and
caller reset. These are synthetic native presentation frames with no injected input, game
simulation, gameplay win signal or game-memory writes.

```rust,check crate-type=bin
use ferravex_play::ui::theme::*;
use ferravex_render::{
    input::host_frame,
    ui::{ButtonStyle, TextStyle, Ui, UiError, UiRect, Viewport,
         stats::{StatRow, StatRowsLayout, StatRowsStyle},
         text_layout::{LineLimit, WrappedText}},
};

fn text(theme: UiTheme, role: TextRole) -> TextStyle {
    let token = theme.text(role);
    TextStyle { size: token.size, color: token.color, wrap: true, ..TextStyle::default() }
}
fn block(copy: &str, x: f32, y: f32, width: f32, style: TextStyle) -> Result<UiRect, UiError> {
    let measured = WrappedText::new(copy, width, style.size)?.measure();
    if measured.width > width { return Err(UiError::InvalidLayout); }
    Ok(UiRect { min: [x, y], size: [width, measured.required_height] })
}
fn show(ui: &mut Ui, theme: UiTheme, width: f32, height: f32) -> Result<(), UiError> {
    let viewport = Viewport::responsive([width, height], [8., 12., 8., 12.])?;
    let s = theme.spacing();
    let panel = viewport.bounds().inset([s.inset; 4])?;
    let inner = panel.inset([s.inset; 4])?;
    let [x, mut y] = inner.min;
    let w = inner.size[0];
    let heading = text(theme, TextRole::Heading);
    let body = text(theme, TextRole::Body);
    let label = text(theme, TextRole::Label);
    let title = block("INSPECTOR", x, y, w, heading)?;
    y += title.size[1] + s.gap;
    let rows = [StatRow { label: "GRIP", value: "0.80", description: Some("ACCEPTED") }];
    let stats = StatRowsLayout::new(UiRect { min: [x, y], size: [w, inner.size[1]] }, &rows,
        StatRowsStyle { label, value: body, description: label,
            column_gap: s.inset, row_gap: s.gap, stack_gap: s.compact_gap,
            description_gap: s.compact_gap })?;
    if stats.report().hidden_rows != 0 || stats.report().width_overflow {
        return Err(UiError::InvalidLayout);
    }
    y += stats.report().required_height + s.gap;
    let warning = theme.state(ThemeState::Warning);
    assert_eq!(warning.cue.pattern, CuePattern::Dots);
    let copy = "WARNING: HEALTH 50 / 100";
    let value = block(copy, x, y, w, body)?;
    y += value.size[1] + s.compact_gap;
    let track = UiRect { min: [x, y], size: [w, s.control_height] };
    let well = track.inset([s.stroke; 4])?;
    let fill = UiRect { size: [well.size[0] * 0.5, well.size[1]], ..well };
    y += track.size[1] + s.gap;
    let apply = UiRect { min: [x, y], size: [w, s.control_height] };
    y += s.control_height + s.compact_gap;
    let locked = UiRect { min: [x, y], size: [w, s.control_height] };
    // Existing ButtonStyle owns its fixed 8-unit left/right text padding.
    for copy in ["APPLY", "X LOCKED"] {
        if WrappedText::new(copy, f32::MAX, body.size)?.measure().width + 16. > w {
            return Err(UiError::InvalidLayout);
        }
    }
    if locked.min[1] + locked.size[1] > inner.min[1] + inner.size[1] {
        return Err(UiError::InvalidLayout); // Caller must expand/scroll/fallback.
    }
    let buttons = ButtonStyle { fill: theme.color(ColorRole::Surface),
        disabled: theme.color(ColorRole::Surface), ink: theme.color(ColorRole::Text),
        focus: theme.color(ColorRole::Focus), size: body.size };
    host_frame(0., width as u32, height as u32, || -> Result<(), UiError> {
        ui.begin(viewport);
        ui.compose(|g| {
            g.panel(viewport.bounds(), theme.color(ColorRole::Canvas))?;
            g.panel(panel, theme.color(ColorRole::Surface))?;
            g.wrapped_text(title, "INSPECTOR", heading, LineLimit::Unlimited)?;
            stats.submit(g)?;
            g.wrapped_text(value, copy, body, LineLimit::Unlimited)?;
            g.panel(track, theme.color(ColorRole::Border))?;
            g.panel(well, theme.color(ColorRole::Canvas))?;
            g.panel(fill, warning.foreground)?;
            // Static dots supplement fill hue. Numeric value remains outside it.
            for fraction in [0.2, 0.5, 0.8] {
                g.panel(UiRect { min: [fill.min[0] + fill.size[0] * fraction,
                    fill.min[1] + fill.size[1] * 0.5], size: [s.stroke; 2] },
                    theme.color(ColorRole::Canvas))?;
            }
            g.button(1, apply, "APPLY", true, buttons)?;
            g.button(2, locked, "X LOCKED", false, buttons)?;
            Ok(())
        })?;
        ui.finish(true);
        for (id, rect, enabled) in [(1, apply, true), (2, locked, false)] {
            let element = ui.inspect().unwrap().find(|e| e.id == Some(id)).unwrap();
            assert_eq!(element.bounds, rect);
            assert_eq!(element.visible_bounds, Some(rect));
            assert_eq!(element.enabled, enabled);
            assert!(element.interaction_registered);
        }
        ui.paint(); // CPU retained paint, not a window/device readability test.
        Ok(())
    })
}
fn main() -> Result<(), UiError> {
    let mut ui = Ui::new(); // Caller retains it across frames.
    ui.set_inspection_enabled(true);
    for mode in [ThemeMode::Normal, ThemeMode::HighContrast] {
        for factor in [1., 1.5] {
            let mut theme = UiTheme::preset(mode);
            theme.set_metrics(theme.types().try_scaled(factor).unwrap(),
                Spacing { control_height: 56., ..theme.spacing() }).unwrap();
            for width in [352., 960.] { show(&mut ui, theme, width, 800.)?; }
            assert_eq!(show(&mut ui, theme, 352., 120.), Err(UiError::InvalidLayout));
        }
    }
    let reset = UiTheme::preset(ThemeMode::Normal);
    assert_eq!(reset.types().body, 18.);
    Ok(())
}
```
