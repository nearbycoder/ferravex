# 3D Physics Lab

A low-poly loading yard for testing Ferravex's original rotational 3D solver. Boxes stack inside a fixed floor and curbs while spheres drop into the scene. A 120 Hz fixed clock and interpolated positions/rotations drive cached flat-normal meshes, directional vertex light and distance fog. The sandbox is bounded to 180 dynamic bodies.

Native platform support and verification limits are documented in [Platforms](../../docs/PLATFORMS.md). Browser play uses the shared first-party WebGL2 host.

```sh
cargo run --release -p physics-3d
cargo run --release -p physics-3d -- --smoke-frames 360 --screenshot /tmp/physics-3d.png
cargo check -p physics-3d --target wasm32-unknown-unknown
```

Drag with the left mouse button or use arrows to orbit the camera; use the wheel to zoom. Press 1 to drop a crate, 2 to drop a ball, Space to pause and R to reset. All geometry and text are generated by first-party code. The immediate renderer has no shadow-map pass.

This sandbox has no win condition. Check stacking, angular response, ball contacts, body limits, reset/pause and camera behavior. Its solver is a bounded original implementation with documented shape, joint and CCD limits; see the `ferravex-physics` README rather than assuming production physics coverage.

Press F, the gamepad left shoulder or PULSE for a mass-normalized radial kick, with a 0.65-second cooldown. Pulses wake bodies and pass through the normal physics solver.
