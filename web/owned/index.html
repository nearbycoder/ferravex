How to play

Use Tab and Shift + Tab to reach page controls; Enter or Space activates a focused button. Choose Enter / Resume training to focus the canvas and capture the mouse. 2D overview starts without mouse capture; movement stays active. With the canvas focused, Enter starts or resumes the first-person view. Click the scene if mouse capture is needed.

Default keyboard and mouse controls

Saved or remapped bindings may differ from these defaults and the drill hints. Open Controls or press F2 with the canvas focused to inspect or change bindings. Tab is reserved for page navigation here. In Controls, use Up / Down and Enter to select a binding. Escape cancels an active remap; otherwise it closes Controls. F2 also closes Controls.

Reset training
Scene tools → Reset clears training, scene edits and recording. Disconnect a peer session first.

Release mouse capture with Escape before navigating the page. Leaving the canvas for a page control, switching away from the window, or opening Controls releases gameplay input. Offline training keeps its progress and waits for an explicit resume. Connected matches stay live while your local controls are released. Closing Controls does not resume training. On short screens, scroll beside the scene using the labelled strip; keyboard users can focus that strip and use arrow keys. Moving focus out of the scene pauses offline training.

Scene tools opens the scene, shader, replay and LAN tools. Escape or Close returns to this menu. Details → Player tools contains presentation and accessibility settings, screenshots and settings backups. Close Details with Escape or Done to return focus to the canvas. Fullscreen may consume the first Escape to exit.

Scene tools

Reset clears training, scene edits and recording. It is unavailable during a connected match.

Two-player LAN session

Exchange tokens directly with your teammate over a trusted channel. This prototype has no relay or accounts. Both peers need a route to each other.
