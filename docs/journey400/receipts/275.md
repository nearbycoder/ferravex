## Concrete behavior and compatibility

Continuous telemetry uses finite f64 current/capacity with positive capacity and
0 <= current <= capacity. There is no implicit clamp, smoothing, time ownership,
percentage generation or gameplay availability decision. Known 0/positive is
zero fill; explicit Empty means no capacity and paints a dash; Unknown has no
fraction/fill and paints three static bars. Known zero denominators reject
without division; callers explicitly choose Empty or Unknown. Ratio underflow
that would create a false zero also rejects. Fill widths round to f32 logical
geometry, while the original telemetry value and complete display copy remain
available. Full continuous fill equals the entire inner track exactly; known
zero has a zero-width fill and emits no fill vertices.

Segment values use exact integer counts with at most 64 cells. Known requires
positive capacity and filled <= capacity. Empty has zero cells; Unknown can
reserve 0..=64 cells and marks none accepted. Unknown zero capacity still paints
three bars, distinct from Empty's dash. No partial cells, rescaling of gameplay
counts, dropped cells or invented progress is allowed. Segment gaps use the
fixed theme compact_gap; too many cells for readable fixed strokes reject.
Each known cell has an internal border and Canvas well; accepted cell fill
covers that well completely. Continuous thresholds are bounded to 16, validate
finite 0..=1 fractions, stay within the track and retain complete caller labels
below it in caller order. Endpoint strokes move inward by half a stroke to fit;
this placement adjustment never changes a telemetry fraction. Duplicate and
unsorted markers are allowed because meanings/order are authored.

Mandatory nonblank label, display and status strings are borrowed unchanged and
never parsed. The display can deliberately be independent of the fraction
(e.g. a countdown next to energy); callers own precision, units, localization,
meaningful known/empty/unknown wording and synchronization. Strings share a
4096-byte source cap, including threshold labels. Text uses existing WrappedText
and theme label/body sizes, unlimited wrapping, left alignment and no shadow,
ellipsis or size reduction. Unsupported glyphs retain full inspection copy and
use the existing bitmap '?' painting fallback. Whitespace wrapping follows the
existing font layout; no new text engine is introduced.

Renderer layout checks every text block, track, cell, fill cue and threshold
rectangle before returning. Too-short/narrow/zero bounds and unrepresentable
positive rectangles reject explicitly. Pure continuous geometry supports zero
extents and finite negative/fractional origins; zero extents paint nothing.
Pure positive segment cells require representable positive width. Extreme
coordinates/subpixel fills for which the fixed cues cannot be represented may
reject rather than silently omitting a cue. Borders, dots, dashes, bars and
thresholds stay inside track/cell bounds; text has separate reserved rectangles.
Known fills have three static Canvas dots; full supplied status text remains
outside the fill. No motion, flash, audio, input registration or remapping changes.

`draw` uses one existing Ui::compose transaction. `submit` uses one nested
composition so ordinary command/text/vertex/clip errors restore this meter's
paint, inspection copy and clip state. Propagate `?` to reject a surrounding card
or handle a nested failure with a local fallback. Underlying UI budgets remain
authoritative: successful layout alone does not guarantee submission capacity.
No allocation/panic-abort or external callback rollback guarantee is added.
Construction/geometry and submission use fixed local arrays and existing UI
arenas. Caller output slices reject before mutation and retain their unused tail
on success. Reset is replacement from a new snapshot, with no internal cache.

Returned layout rectangles are exactly those submitted for retained inspection.
The passive composer installs no hit regions. Callers must reserve the bounds
inside their viewport/safe area and any inherited clip; an outer clip can still
hide a valid composition. This is geometry/CPU painting evidence, not physical
font readability or device accessibility evidence. Theme normal/high-contrast
colors/types are explicit opt-in arguments, with no global/default theme changes.
Existing public literals/enums, authored game defaults/palettes, custom software
hosts, native/Wasm exports and wire/save/replay formats are untouched.

## Runnable first-party recipe: accepted ammo, reload and actual ticks

This complete native/headless example calls the existing Magazine acceptance
methods and GameSession fixed steps, never writes a fictional game state/time,
never injects game/browser input, and never claims a win. All elapsed values are
explicit test inputs. A local-overlay label does not pause the session. It checks
zero ticks, pause discard, manual step, catch-up, accepted completion exactly once,
exact supplied displayed copy/fill, full ammo and caller reset. Display is a
countdown; fraction comes directly from Magazine::reload_status().progress.

```rust,check crate-type=bin
use ferravex_core::session::GameSession;
use ferravex_play::{gameplay::magazine::Magazine,
    ui::{meters::*, theme::*}};
use ferravex_render::{input::host_frame,
    ui::{Ui, UiError, UiLabel, UiRect, Viewport, meters::*}};

fn show(ui: &mut Ui, magazine: &Magazine, status: &str) -> Result<(), UiError> {
    let theme = UiTheme::preset(ThemeMode::Normal);
    let viewport = Viewport::responsive([352., 700.], [8., 12., 8., 12.])?;
    let snapshot = magazine.reload_status();
    let display = match snapshot {
        Some(s) => format!("{:.6}s REMAINING", s.remaining_seconds),
        None => "NO ACTIVE RELOAD".to_owned(),
    };
    let value = match snapshot {
        Some(s) => MeterValue::Known { current: f64::from(s.progress), capacity: 1. },
        None => MeterValue::Empty,
    };
    let markers = [Threshold { fraction: 0.5, label: "HALF DURATION" }];
    let reload = MeterLayout::meter(
        UiRect { min: [16., 12.], size: [304., 280.] },
        MeterCopy { label: "RELOAD", display: &display, status }, value, &markers, theme)?;
    let ammo_copy = format!("{} / {}", magazine.loaded(), magazine.capacity());
    let ammo = MeterLayout::segments(
        UiRect { min: [16., 312.], size: [304., 280.] },
        MeterCopy { label: "ACCEPTED AMMO", display: &ammo_copy, status },
        SegmentValue::Known { filled: usize::from(magazine.loaded()),
            capacity: usize::from(magazine.capacity()) }, theme)?;
    if let Some(s) = snapshot {
        let geometry = reload.continuous().unwrap();
        assert_eq!(geometry.value().fraction().unwrap(), Some(f64::from(s.progress)));
        assert_eq!(geometry.fill().unwrap().size[0], geometry.bounds().size[0] * s.progress);
    }
    assert_eq!(ammo.cells().iter().filter(|c| c.filled).count(), usize::from(magazine.loaded()));
    host_frame(0., 352, 700, || -> Result<(), UiError> {
        ui.begin(viewport);
        ui.compose(|g| { reload.submit(g)?; ammo.submit(g) })?;
        ui.finish(true);
        for (copy, rect) in [(&display, reload.regions().display), (&ammo_copy, ammo.regions().display)] {
            let e = ui.inspect().unwrap().find(|e| e.label == UiLabel::Full(copy)).unwrap();
            assert_eq!(e.painted_label, copy);
            assert_eq!(e.bounds, rect);
            assert_eq!(e.visible_bounds, Some(rect));
        }
        assert!(ui.inspect().unwrap().all(|e| !e.interaction_registered));
        ui.paint();
        Ok(())
    })
}
fn main() -> Result<(), UiError> {
    let mut session = GameSession::try_new(64., 4, true).unwrap();
    let mut magazine = Magazine::new(6, 6, 2.).unwrap();
    for _ in 0..3 { assert!(magazine.fire()); }
    assert!(magazine.reload());
    assert!(!magazine.fire());
    let initial = magazine.reload_status();
    let mut ui = Ui::new();
    ui.set_inspection_enabled(true);
    show(&mut ui, &magazine, "RELOADING")?;
    assert_eq!(session.advance(0.5 / 64.).steps, 0);
    assert_eq!(magazine.reload_status(), initial);
    session.set_paused(true);
    assert_eq!(session.advance(30.).steps, 0);
    show(&mut ui, &magazine, "PAUSED")?;
    assert_eq!(magazine.reload_status(), initial);
    let mut executed = 0;
    let mut completions = 0;
    let manual = session.step_paused().unwrap();
    for dt in manual.ticks() {
        executed += 1;
        completions += usize::from(magazine.advance(dt).unwrap());
    }
    show(&mut ui, &magazine, "PAUSED AFTER STEP")?;
    assert_eq!(magazine.remaining(), 1.984375);
    session.set_paused(false);
    let catch_up = session.advance(3. / 64.);
    assert_eq!(catch_up.steps, 3);
    for dt in catch_up.ticks() {
        executed += 1;
        completions += usize::from(magazine.advance(dt).unwrap());
    }
    show(&mut ui, &magazine, "LOCAL MENU; RELOAD CONTINUES")?;
    assert_eq!(executed, 4);
    assert_eq!(session.tick(), 4);
    assert_eq!(magazine.remaining(), 1.9375);
    while magazine.reloading() {
        let batch = session.advance(4. / 64.);
        for dt in batch.ticks() {
            executed += 1;
            completions += usize::from(magazine.advance(dt).unwrap());
        }
    }
    assert_eq!((executed, completions), (128, 1));
    assert_eq!((magazine.loaded(), magazine.reserve()), (6, 3));
    assert!(!magazine.advance(1.).unwrap());
    show(&mut ui, &magazine, "RELOAD COMPLETE")?;
    session.restart();
    magazine = Magazine::new(6, 6, 2.).unwrap();
    assert_eq!(session.tick(), 0);
    show(&mut ui, &magazine, "RESET; FULL AMMO")?;
    Ok(())
}
```
