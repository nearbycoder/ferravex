Emberline

A 2D platformer: carry the lantern to the green exit lift. Land beside each numbered lantern to save a checkpoint. Embers are optional; falls return you to the last lit lantern.

The keys below are default bindings. Choose Controls or press F2 in the game to inspect or remap your current bindings. Saved bindings take precedence over this guide.

Default keyboard controls

Start / confirm
Enter starts, resumes a paused run, or retries after completion.
Move
A / D or Left / Right arrow keys.
Jump
Space, W or Up. Tap for a short hop; hold for a higher jump.
Pause / resume
Escape during a run.
Restart
R resets the whole run, including checkpoints and collected embers, even while paused.

Focus, menus and remapping

Focus the game canvas to play. Pause before moving to page controls or reading this guide. With Controls closed, Tab and Shift + Tab move between the game and page controls. This page reserves Tab for navigation; choose another key when remapping gameplay.

Inside Controls, use Tab or the arrow keys to select a row and Enter to activate it. Escape cancels a binding capture; press it again to close Controls. F2 also closes Controls. Closing Controls does not resume a manually paused run.

Details → Player tools contains presentation preferences, screenshots and sharing. Use Done or Escape to close Details and return focus to the game. Fullscreen may use Escape to exit first; its Exit button is also available.

For touch play, the default layout has movement, jump and pause buttons, plus a start/resume/retry card. Controls shows your current touch layout. Scroll this guide outside the game canvas.
