## Behavior, units and compatibility

`Canvas2D::try_fit` and `try_fit_in` are nonpanicking, allocation-free
constructors returning `Result<Option<Canvas2D>, HudLayoutError>`. They reuse
the existing layout error type rather than expanding an existing enum or adding
a parallel error hierarchy.

- `size` is the authored positive, finite world extent. It is never replaced by
  screen/content dimensions. World origin remains top-left, positive Y down.
- `screen` is the full host logical screen, finite and nonnegative, including
  reserved HUD space. `content: ferravex_play::ui::Rect` has absolute logical
  screen `min` and `size`, not world units or renderer `Rect { x, y, w, h }`.
  Content must be finite, nonnegative and wholly inside the screen.
- `scale` is logical screen pixels per world unit; `offset` is the displayed
  world top-left in absolute logical pixels. Safe-area offsets occur once.
- Structurally invalid dimensions/rectangles return
  `Err(HudLayoutError::InvalidLayout)` before the suspension branch, including
  invalid world dimensions on a zero-sized screen. After structural validation,
  either content dimension below **one logical pixel** returns `Ok(None)`,
  matching task 271. Callers skip world rendering/input for that result and
  reconstruct on resize; no stale transform is retained inside the API.
- Nonfinite/nonpositive derived scale, displayed extent or camera zoom,
  collapsed displayed edges, overflow and out-of-content rounded geometry are
  errors. A one-ULP inward scale correction prevents division/multiplication
  rounding from expanding the displayed world into adjacent content. Extremely
  large/small finite inputs can therefore be rejected.
- `from_fit` copies task 271's already-validated `CanvasFit` without recomputing
  its scale/rectangle. Use `hud.fit_canvas(size)?.map(Canvas2D::from_fit)`.
  The existing fit type has private fields; this adapter cannot receive an
  arbitrary caller-authored invalid fit.
- `camera()` now accounts for asymmetric `Canvas2D.offset`. Camera translation
  is normalized and positive Y up, consistent with the existing camera matrix.
  Computing displacement relative to the old centered offset preserves exactly
  zero translation for legacy centered fits. Target and zoom formulas remain
  unchanged. No raw GPU viewport or scissor is introduced.
- `project`/`unproject` remain unclipped world/logical-screen arithmetic.
  `pointer_half_open` uses the displayed logical screen rectangle before
  unprojection: left/top are included, right/bottom excluded, matching
  `Viewport::unproject` and HUD rectangles. Nonfinite pointer input or basic
  malformed public transform dimensions return `None`. The existing `pointer`
  retains its inclusive right/bottom boundaries.
- Browser `Touch.position` and mouse inputs are already logical screen pixels;
  pass them directly. The host applies DPR only at framebuffer conversion.
  Do not multiply the constructor/rectangle/input by DPR. Native hosts retain
  their existing supplied coordinate policy; automatic native DPI support is
  not introduced.

The original `fit(size, screen) -> Self` implementation, signature, assertion
behavior and arithmetic are unchanged, including positive subpixel fits. Its
panicking invalid-input contract is now explicit in rustdoc. Public struct
fields/literals, derives, save/replay/wire formats, exports and feature gates
are unchanged. Manually mutating fields bypasses constructor guarantees;
existing unclipped methods are not retrofitted with validation.

## Runnable first-party consumer recipe

This complete headless binary uses production methods, retains an existing
canvas's world framing, and verifies camera/input agreement after HUD fitting,
synthetic DPR conversion and resize-to-zero suspension. It does not draw pixels
or drive browser input. Touch positions and DPR values are synthetic data.

```rust,check crate-type=bin
use ferravex_play::ui::{HudEdge, HudLayoutError, HudRegions, Viewport};
use ferravex_render::{Camera, Touch, TouchPhase, Vec2, canvas::Canvas2D, vec2};

fn fit_existing(canvas: Canvas2D, hud: &HudRegions)
    -> Result<Option<Canvas2D>, HudLayoutError>
{
    Ok(hud.fit_canvas(canvas.size.to_array())?.map(Canvas2D::from_fit))
}

fn main() -> Result<(), HudLayoutError> {
    let world = vec2(1280., 720.);
    for screen in [vec2(640., 320.), vec2(390., 844.), vec2(2560., 720.)] {
        let original = Canvas2D::try_fit(world, screen)?.unwrap();
        let mut hud = HudRegions::new(screen.to_array(), [8., 24., 12., 16.], [160., 100.])?;
        hud.reserve("header", HudEdge::Top, 76.)?;
        hud.reserve("actions", HudEdge::Bottom, 44.)?;
        hud.reserve("sidebar", HudEdge::Left, 30.)?;
        let canvas = fit_existing(original, &hud)?.unwrap();
        let direct = Canvas2D::try_fit_in(original.size, screen, hud.content())?.unwrap();
        assert_eq!(canvas.size, original.size);
        assert_eq!(canvas.screen, screen);
        assert_eq!(canvas.offset, direct.offset);
        assert_eq!(canvas.scale, direct.scale);
        let matrix = canvas.camera().matrix(screen.x, screen.y);
        for point in [vec2(100., 100.), world * 0.5, vec2(1200., 700.)] {
            let logical = canvas.project(point);
            assert!(canvas.unproject(logical).distance(point) < 0.002);
            let ndc = matrix.project_point3(point.extend(0.));
            for dpr in [1., 1.25, 2., 3.] {
                let framebuffer = vec2(
                    (ndc.x + 1.) * screen.x * 0.5,
                    (1. - ndc.y) * screen.y * 0.5,
                ) * dpr;
                assert!((framebuffer / dpr).distance(logical) < 0.002);
                let touch = Touch {
                    id: 1,
                    position: framebuffer / dpr,
                    phase: TouchPhase::Started,
                };
                assert!(canvas.pointer_half_open(touch.position).unwrap().distance(point) < 0.002);
            }
        }
        let ui = Viewport::responsive(screen.to_array(), [0.; 4]).unwrap();
        for region in hud.regions() {
            let center = Vec2::from(region.rect.min) + Vec2::from(region.rect.size) * 0.5;
            assert!(region.rect.contains(ui.unproject(center.to_array()).unwrap()));
            assert!(canvas.pointer_half_open(center).is_none());
        }
        let suspended = HudRegions::new([0.; 2], [0.; 4], [0.; 2])?;
        assert!(fit_existing(canvas, &suspended)?.is_none());
    }
    let mut hud = HudRegions::new([800., 600.], [0.; 4], [0.; 2])?;
    let footer = hud.reserve("footer", HudEdge::Bottom, 100.)?;
    let canvas = Canvas2D::from_fit(hud.fit_canvas([800., 500.])?.unwrap());
    let shared_edge = canvas.project(vec2(400., 500.));
    assert!(footer.contains(shared_edge.to_array()));
    assert_eq!(canvas.pointer_half_open(shared_edge), None);
    assert_eq!(canvas.pointer(shared_edge), Some(vec2(400., 500.)));
    assert!(Canvas2D::try_fit(Vec2::ZERO, vec2(800., 600.)).is_err());
    Ok(())
}
```
