## Concrete behavior and compatibility

- Produces the **same existing Arena**, with its original vectors/order/values. Legacy raw literals, `Arena::default`, ID-modulo spawn selection and raw empty-vector origin fallback remain intact. No map schema, collision detector, spawn selector, input/rule/tick change, wire/checkpoint/replay context layout or platform export was added.
- Explicit caller caps may be 0 through 256 solids and 0 through MAX_PLAYERS (currently 16) spawns. Oversized settings fail before reservation; they are never clamped. Defaults are these hard maxima. Existing checkpoint caps are private, so this module documents/mirrors them and tests successful checkpoint encoding at the exact caps.
- Solid checks report zero-based source index and nonfinite center, nonfinite half extents, nonpositive half extents, nonrepresentable derived min/max, center component range or half-extents component range. **Zero and negative extents are rejected**, matching existing checkpoint and character cuboid geometry. All axes are checked. Min/max arithmetic is checked before component ranges so finite arithmetic overflow has an explicit diagnostic.
- Checkpoint ranges are preserved: absolute solid center components <=8192, strictly positive solid half extents <=8192, absolute spawn components <=4096. Without clearance, character-specific planar restrictions/penetration are not imposed: very small positive extents, nonzero Z and below-ground spawns remain acceptable raw authoring data when the checkpoint permits them. Large finite values outside the checkpoint domain are rejected; geometry is never normalized or spawn positions rewritten.
- Default checked empty policy is Reject. Explicit LegacyOrigin preserves the empty vector and original origin fallback. If clearance is enabled, the fallback origin is checked and labeled `SpawnSite::LegacyOrigin`.
- Clearance is opt-in and defaults, when requested with `SpawnClearance::default()`, to the actual FPS capsule radius 0.3/full height 1.8. Authors may supply any existing valid Capsule or Box2 shape. All membership layers are included; the authoring API does not allow a mask to ignore the actual arena geometry.
- Clearance calls task 228's actual `character::check_clearance` on the **actual Arena Terrain adapter**, preserving current poses, its implicit ground obstacle ID 0, solid ID source-index+1 mapping, touching tolerance `1e-5`, supported shape restrictions and complete-query rules. It never recovers/snaps/moves a spawn.
- Per-spawn candidate budgets are explicit in 0..=1,000,000. Default 257 covers the implicit ground plus all 256 solids. The always-visited implicit ground consumes a candidate even for an elevated spawn. QueryBudget is preserved as QueryBudget, including when a blocker preceded exhaustion; it never authorizes acceptance. Budget resets for each spawn.
- Clearance failures include authored source spawn index or explicit fallback, source solid index when applicable, and the **actual ClearanceError**. Ground and input/budget errors have no solid index. Blocked maps the helper's stable ID directly. For InvalidObstacle (which has no ID), an error-only diagnostic pass uses the same Arena visitor and existing helper on each visited singleton to recover the first invalid solid's index. No new collision algorithm or scratch vector is used.
- Final validation order: options, counts, every solid in vector order, every spawn in vector order, empty policy, clearance in spawn order. It returns the first error, never a truncated/partially accepted arena. A valid/clear first entry cannot hide a malformed/blocked final entry. Solids added after spawns are included. Overlapping authored spawn positions are allowed; this is static clearance, not live-player safe spawn selection.
- Builder vectors reserve once at the configured count caps and never grow afterward. Accepted entries remain unchanged on push/validate/finish failure. Push errors return the exact rejected value; finish errors return the complete builder. `reset` retains options/storage and restarts source indices at zero. No clearance history persists. The owned-raw-arena constructor returns exact caller vectors on failure; it preserves caller capacity rather than claiming to retroactively bound an already supplied allocation.
- Allocator exhaustion during constructor reservation follows std Vec behavior and is not recovered. A narrowly scoped `#[allow(clippy::result_large_err)]` on `finish` deliberately permits its bounded inline owned-builder error (144 bytes on this host) to avoid allocating a Box on failure. Strict Clippy passes with this documented exception.

## Exact public API

All names below are under `ferravex_fps::arena_authoring`. These are signature/type excerpts, not runnable snippets. Defaults and semantics are documented in the module.

```rust
pub const MAX_SOLIDS: usize = 256;
pub const MAX_SPAWNS: usize = MAX_PLAYERS;

pub struct ArenaLimits { pub solids: usize, pub spawns: usize }
pub enum EmptySpawnPolicy { Reject, LegacyOrigin }
pub struct SpawnClearance {
    pub shape: CharacterShape,
    pub max_candidates: usize,
}
pub struct AuthoringOptions {
    pub limits: ArenaLimits,
    pub empty_spawns: EmptySpawnPolicy,
    pub clearance: Option<SpawnClearance>,
}
pub enum SolidError {
    NonFiniteCenter, NonFiniteHalfExtents, NonPositiveHalfExtents,
    NonFiniteBounds, CenterLimit, HalfExtentsLimit,
}
pub enum SpawnError { NonFinite, PositionLimit }
pub enum SpawnSite { Authored(usize), LegacyOrigin }
pub enum ArenaAuthoringError {
    InvalidLimits { limits: ArenaLimits },
    InvalidClearance,
    SolidCapacity { index: usize, limit: usize },
    SpawnCapacity { index: usize, limit: usize },
    Solid { index: usize, problem: SolidError },
    Spawn { index: usize, problem: SpawnError },
    EmptySpawns,
    SpawnClearance {
        spawn: SpawnSite, solid: Option<usize>, error: ClearanceError,
    },
}
pub struct Rejected<T> { pub error: ArenaAuthoringError, pub input: T }
pub struct ArenaBuilder { /* private fields */ }

pub fn validate_arena(arena: &Arena, options: AuthoringOptions)
    -> Result<(), ArenaAuthoringError>;
pub fn try_from_arena(arena: Arena, options: AuthoringOptions)
    -> Result<Arena, Rejected<Arena>>;
impl ArenaBuilder {
    pub fn new(options: AuthoringOptions) -> Result<Self, ArenaAuthoringError>;
    pub fn arena(&self) -> &Arena;
    pub fn options(&self) -> AuthoringOptions;
    pub fn try_push_solid(&mut self, input: Obstacle)
        -> Result<usize, Rejected<Obstacle>>;
    pub fn try_push_spawn(&mut self, input: Vec3)
        -> Result<usize, Rejected<Vec3>>;
    pub fn validate(&self) -> Result<(), ArenaAuthoringError>;
    pub fn reset(&mut self);
    pub fn finish(self) -> Result<Arena, Rejected<Self>>;
}
```

ArenaLimits, SpawnClearance and AuthoringOptions implement Default/Clone/Copy/Debug/PartialEq; ArenaLimits also Eq. EmptySpawnPolicy derives Default (Reject), Clone/Copy/Debug/PartialEq/Eq. SolidError, SpawnError, SpawnSite and ArenaAuthoringError derive Clone/Copy/Debug/PartialEq/Eq. ArenaAuthoringError also implements Display and std::error::Error. Rejected<T> and ArenaBuilder implement Debug.
