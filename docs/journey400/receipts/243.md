Behavior and compatibility:

- One shared evaluator computes previews and committed awards, with no allocations,
  callbacks, platform I/O, clocks or rendering. At most 1023 promotions. Existing
  `award` returns exactly the evaluator's promotions.
- Preserve saturating `u64` addition BEFORE promotion subtraction. Reports distinguish
  requested XP, accepted addition delta, discarded XP, cost spent and retained XP.
  `accepted_xp` is not the final remainder delta. `saturated` means discarded XP is
  nonzero; reaching exactly `u64::MAX` without discarding is not saturation.
- Cap retains excess within `u64`; cap does not itself discard an award. At cap,
  future awards may fill/saturate retained XP but produce no promotions/costs.
  Normal nonsaturating partitioning is equivalent. Saturating partitioning need
  not be: earlier subtracted costs can free room before later additions. The old
  “no lost overflow XP” comment was inaccurate and is replaced, not implemented
  as mathematically unbounded XP.
- Reports expose before/after level and remainder, total new promotions, XP spent
  and resulting cap state. XP accounting is exact. `xp_spent` is bounded by
  `u32::MAX * (1023 * 1024 / 2)`, which fits `u64`.
- Snapshots carry exact base, growth, maximum, level and XP values, with no hash
  identity, codecs or new save format. Restoration checks authoring, every curve
  value, level bounds, then normalized remainder strictly below next cost unless
  capped. At cap every `u64` remainder is valid. All checks precede replacement;
  invalid restore preserves the complete state and future award behavior.
- Repeated identical restore is a state observation with equal before/after;
  its report has no promotions field. Older same-curve snapshots deliberately
  allow rollback. A stale snapshot from a changed curve is rejected, even when
  the current next cost coincides. No timestamp/revision/anti-replay promise.
- Legacy constructor bounds (`base > 0`, maximum 1–1024), zero growth,
  `base + growth * (level - 1)` costs, next_cost/cap behavior, private Progression
  fields, LoopError and all existing public signatures remain compatible.
  No manifests, roots, wire/save/replay bytes, Wasm/native exports or game formulas
  changed. All new types are ordinary in-memory values.

```rust
pub struct AwardReport {
    pub requested_xp: u64,
    pub accepted_xp: u64,
    pub discarded_xp: u64,
    pub saturated: bool,
    pub level_before: u16,
    pub level_after: u16,
    pub promotions: u16,
    pub xp_before: u64,
    pub xp_spent: u64,
    pub xp_after: u64,
    pub at_cap: bool,
}
pub struct ProgressionSnapshot {
    pub base: u32,
    pub growth: u32,
    pub maximum: u16,
    pub level: u16,
    pub xp: u64,
}
pub enum RestoreError { InvalidCurve, CurveMismatch, InvalidLevel, UnsettledXp }
pub struct RestoreReport {
    pub before: ProgressionSnapshot,
    pub after: ProgressionSnapshot,
}
// All four new types derive Clone, Copy, Debug, PartialEq, Eq.
impl Progression {
    pub fn preview_award(&self, amount: u64) -> AwardReport;
    pub fn award_report(&mut self, amount: u64) -> AwardReport;
    pub fn snapshot(&self) -> ProgressionSnapshot;
    pub fn restore(&mut self, snapshot: ProgressionSnapshot)
        -> Result<RestoreReport, RestoreError>;
}
```

```rust,check crate-type=bin
use ferravex_core::session::GameSession;
use ferravex_play::{
    gameplay::{progression::Progression, upgrades::Upgrades},
    objective::{ObjectiveGraph, ObjectiveKind, ObjectiveSpec, ObjectiveState},
};

fn main() {
    let mut session = GameSession::try_new(64.0, 4, true).unwrap();
    let mut xp = Progression::new(50, 30, 4).unwrap(); // Neon's actual curve.
    let mut upgrades = Upgrades::new([3]).unwrap(); // Neon's actual rank cap.
    let spec = |id| ObjectiveSpec {
        id, all: 0, any: 0, exclusive_group: 0,
        kind: ObjectiveKind::Event { id, count: 1 },
    };
    let mut objectives = ObjectiveGraph::new(243, [spec(1), spec(2)]).unwrap();
    let initial = (xp.snapshot(), upgrades, objectives.snapshot());
    // Already-authorized quest events: (kind, serial, authored completion XP).
    // The repeated serial represents duplicate delivery, not another action.
    let events = [(1, 1, 50), (1, 1, 50), (2, 2, 80)];
    let mut executed = 0;
    let mut rewarded_promotions = 0;
    let local_overlay_open = true;
    assert!(local_overlay_open); // Masks local commands, never pauses authority.

    let zero = session.advance(0.5 / 64.0);
    assert_eq!(zero.steps, 0); // No event consumed, preview grants nothing.
    assert_eq!(xp.preview_award(50).promotions, 1);
    assert_eq!(upgrades.rank(0), Some(0));
    let batch = session.advance(3.5 / 64.0);
    assert_eq!(batch.steps, 4);
    for _ in 0..batch.steps {
        if !session.is_playing() { break; } // Stop an issued batch at terminal.
        let (kind, serial, amount) = events[executed];
        executed += 1;
        let accepted = objectives.event(kind, 1, serial).unwrap();
        if accepted.completed != 0 {
            let preview = xp.preview_award(amount); // Advisory only.
            let report = xp.award_report(amount); // New accepted completion.
            assert_eq!(preview, report);
            for _ in 0..report.promotions {
                upgrades.apply(0).unwrap();
                rewarded_promotions += 1;
            }
        }
        if objectives.iter().all(|v| v.state == ObjectiveState::Complete) {
            assert!(session.finish(true));
        }
    }
    assert_eq!((session.tick(), executed), (4, 3)); // Issued vs executed.
    assert_eq!((xp.level(), xp.xp(), rewarded_promotions), (3, 0, 2));
    assert_eq!(upgrades.rank(0), Some(2)); // Duplicate event issued no reward.
    assert_eq!(session.advance(1.0).steps, 0); // Finished game stays terminal.

    let saved = xp.snapshot();
    for _ in 0..2 {
        let loaded = xp.restore(saved).unwrap();
        assert_eq!(loaded.before, loaded.after);
    }
    assert_eq!(upgrades.rank(0), Some(2)); // Restore never grants a rank.
    // Trusted paired in-memory restart: reset all model state, not just XP.
    // For untrusted saves, validate the whole game transaction before publishing.
    xp.restore(initial.0).unwrap();
    upgrades = initial.1;
    objectives.restore(initial.2).unwrap();
    session.restart();
    assert_eq!((session.tick(), xp.level(), xp.xp()), (0, 1, 0));
    assert_eq!(upgrades.rank(0), Some(0));
    assert_eq!(objectives.last_event_serial(), 0);
}
```
