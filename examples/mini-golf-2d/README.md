# Copper Greens 2D

A twelve-hole miniature-golf game using the shared [Copper Greens course](../shared/mini-golf/README.md).

Run with `cargo run --release -p mini-golf-2d`. Use the aim/power buttons and
PUTT, or drag toward your target and release. Controls / F2 shows current saved
bindings. Practice selects any of the twelve holes; the scorecard records every
accepted putt and penalty. Aces, birdies, bank and trick shots, lip-outs and a
secret copper assist all get their own celebration, and a full round ends with a
rank title and personal-best hook. See the shared guide for the full course,
rules and feedback details.
