## Concrete behavior and compatibility

- Default is off. `set_inspection_enabled(true)` allocates one bounded optional
  storage object once; inspection becomes available on the **next `begin`**.
  Repeated enabling is idempotent. Enabling mid-composition cannot reconstruct
  already shortened labels and returns no inspector until the next begin.
  `set_inspection_enabled(false)` immediately releases supplemental storage and
  disables both queries/export, preserving already composed paint/input state.
- Off instances retain original command/widget/text capacities and acceptance,
  and do not allocate supplemental metadata/text. `Ui` gains one optional boxed
  pointer; fixed-size accounting therefore changes by that field. No existing
  command is enlarged. `reserved_bytes` accounts for the box and both optional
  arenas when enabled; after disabling it returns to the off-instance value.
- Iteration returns actual accepted commands in composition order: panel,
  gradient, text and button. Ordinary text, `text_fmt`, wrapped text and ordinary
  button labels borrow the existing paint arena. Paint-only entries have no ID,
  `enabled = false`, `focused = false`, and no interaction registration.
- `label` and `hud_button` preserve full original source only when shortened.
  Their supplemental arena is separately limited to **32 KiB UTF-8**, with at
  most **1024** metadata entries (bounded by accepted command count). Unshortened
  labels borrow existing painter text. No duplicate unbounded full-label list
  is maintained; no source is scanned/copied into the supplemental arena when
  inspection is off. UTF-8 is copied whole, without byte-prefix truncation.
- Full-copy capacity misses produce `UiLabel::Unavailable { required_bytes }`.
  `painted_label` still exposes the actual retained prefix/ellipsis. A miss does
  not reject painting/input, consume the remaining supplemental bytes, or
  silently claim the painter prefix is the full label. Later source may still
  fit. Failed UI submissions add neither an inspection entry nor full-label
  bytes/metadata. Existing UI text/command/vertex errors remain unchanged.
- Wrapped/line-limited text reports full retained source as `label` and
  `painted_label`; line suppression still happens in the shared painter. This
  API does not pretend retained text is necessarily painted in full. Task273
  metrics remain the source for line counts/limits.
- `bounds` is the original logical rectangle; `visible_bounds` is its exact
  positive-area intersection with the existing clip, including viewport clip.
  Fully clipped, zero-area and zero-viewport entries remain inspectable with
  `None`. Geometry is **not** an ink/occlusion/contrast/visibility estimate:
  overlapping paint can cover an entry and limited text can paint no glyphs.
  Coordinates use existing logical viewport units and half-open hit semantics;
  hosts project using `viewport.pixels().min + point * viewport.scale()`.
- `enabled` is submitted availability, independent of `finish(false)` or host
  input blocking. Disabled buttons remain interaction-registered and can block
  pointer gestures under task279 semantics. `focused` reflects the current
  eligible registered ID; finish input before reading final focus.
- The latest explicit modal blocker is synthesized from existing modal state,
  at `modal_start`, with its ID, viewport geometry, enabled/registered true and
  focused false. Earlier buttons remain inspectable but have
  `interaction_registered = false`; reused IDs across discarded modal scopes
  are disambiguated by order and registration. Older modal blockers are not
  retained because they no longer exist in interaction state. Maximum traversal
  is 1024 accepted commands plus the current blocker, even with repeated modal
  calls. This changes neither modal interaction nor paint order.
- `begin` clears full-label bytes/metadata and exposes only this composition's
  commands/modal. Borrowed descriptions cannot outlive a mutable UI operation;
  there is no retained history, stale-frame ID cache, input drain, action
  execution API, scene schema, game state export or new global registry.
- Explicit `write_inspection` exports diagnostic **schema 1** JSON into caller
  bytes. It is disabled until the opted-in begin. It performs two bounded passes
  to compute the exact output requirement before writing. Capacity failure or
  disabled inspection leaves the whole caller buffer unchanged; success leaves
  the tail unchanged and returns UTF-8 byte length without a terminator.
  Rectangles are `[x,y,width,height]`; IDs are decimal **strings** for lossless
  u64 transport through JavaScript. Controls/quotes/backslashes are escaped,
  Unicode is preserved, and missing full labels use null plus
  `label_required_bytes`. Schema is diagnostic only, not a scene/save/replay or
  action protocol. Hosts must explicitly opt in and choose publication policy.
- Existing public struct literals/exhaustive enums, button/label defaults,
  `UiInteraction`, input journal delivery and paint/feedback paths are preserved.
  No wire/save/replay or native/Wasm format changed.
