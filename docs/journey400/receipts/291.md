## Concrete behavior

Both batch paths validate handle count (maximum MAX_ACTIONS = 256, counting duplicates), output capacity, then every handle in caller order before any caller-output or map mutation. Failure returns the first applicable error in that order. Empty requests succeed, even on an empty map, and leave all output/input untouched. Larger output buffers are allowed; only the requested prefix is written. Foreign/stale ownership and in-map index bounds use the existing validator. An invalid late handle cannot consume an earlier valid action or partially overwrite output.

Nonconsuming snapshots copy current per-action state, including identical copies for duplicate handles, and preserve every edge/motion value. Consuming reads first copy every snapshot, then clear selected edges and delta values using existing consume_tick semantics. Duplicate outputs are therefore identical, matching actual renderer PlayerInput::take_tick. Re-clearing a duplicate is idempotent. Held axis/button values remain; unselected actions retain edges/motion even when sharing the physical source. Both paths are O(handle count), use caller/inline arrays, and allocate nothing. They do not deduplicate by source or scan action names. More than 256 repeated copies of a single valid handle are still over capacity.

Context/focus/rebinding/config/suppression behavior comes directly from existing stored Action state. This includes the existing release-on-context-deactivation behavior, cleared motion on transitions/focus loss, and suppression of already held buttons on reactivation/rebind/config application. No new focus or global-edge expiration policy was added. Multiple taps before consumption coalesce into pressed/released flags, not counts. Map replacement still expires handles; moving a map retains them.

Atomic means validation and copying/clearing within one exclusively borrowed call, not a cross-thread input transaction. Registration may allocate as before. Callers retain responsibility for consuming only inside actual executed updates and sharing one snapshot across systems.

```rust,check crate-type=bin
use ferravex_core::session::GameSession;
use ferravex_play::input::{Action, ActionKind, ActionMap, Binding, ContextId, InputCode};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut input = ActionMap::default();
    let jump = input.named_action_handle("jump", ActionKind::Button,
        ContextId::GLOBAL, vec![Binding::digital(InputCode::Key(32))])?;
    let pan = input.named_action_handle("pan", ActionKind::Delta,
        ContextId::GLOBAL, vec![Binding::digital(InputCode::MouseDelta(0))])?;
    let mut session = GameSession::try_new(64.0, 4, true)?;
    let (mut issued, mut executed, mut requests, mut motion) = (0_u32, 0_u32, 0_u32, 0.0_f32);
    // Injected (elapsed in fixed intervals, button level, relative host motion).
    for (elapsed, level, delta) in [
        (0.25, 1.0, 3.0), (0.25, 0.0, 5.0),
        (2.0, 0.0, 0.0), (3.0, 1.0, 2.0),
    ] {
        input.feed(InputCode::Key(32), level);
        input.feed_delta(InputCode::MouseDelta(0), delta);
        let batch = session.advance_batch(elapsed / 64.0);
        issued += batch.frame().steps;
        if batch.frame().steps == 0 {
            assert!(input.peek_handles([jump])?[0].pressed);
        }
        for tick in batch.ticks() {
            if !session.is_playing() { break; }
            let [action, duplicate, relative] = input.consume_tick_handles([jump, jump, pan])?;
            assert_eq!(action, duplicate);
            assert_eq!(tick.tick, u64::from(executed + 1));
            // Pass the same snapshot to the update's other systems.
            requests += u32::from(action.pressed);
            motion += relative.value;
            executed += 1;
            if executed == 1 {
                assert!(action.pressed && action.released);
                assert_eq!(relative.value, 8.0);
            }
            if executed == 2 {
                assert_eq!([action, relative], [Action::default(); 2]);
            }
            if executed == 3 { assert!(session.finish(true)); }
        }
    }
    assert_eq!((issued, executed, requests, motion), (5, 3, 2, 10.0));
    assert_eq!(session.tick(), 5); // Issued IDs, including skipped updates.
    input.feed(InputCode::Key(32), 0.0);
    input.feed(InputCode::Key(32), 1.0);
    input.feed(InputCode::Key(32), 0.0);
    assert_eq!(session.advance_batch(1.0).ticks().len(), 0);
    assert!(input.peek_handles([jump])?[0].pressed); // No executed update consumed it.
    session.restart();
    input.suppress_held(); // Explicit caller reset: discard old edges/motion.
    assert_eq!(session.tick(), 0);
    assert_eq!(input.peek_handles([jump, pan])?, [Action::default(); 2]);
    Ok(())
}
```
