# 3D Physics Lab

A low-poly loading yard for testing Ferravex's original rotational 3D solver. Boxes stack inside a fixed floor and curbs while spheres drop into the scene. A 120 Hz fixed clock and interpolated positions/rotations drive cached flat-normal meshes, directional vertex light and distance fog. The sandbox is bounded to 180 dynamic bodies.

The recovery is local and unpublished. Native play requires Linux X11/GLX; browser play uses the shared direct-WebGL2 host. Other native interactive hosts are not implemented. Compile, render and contact behavior need fresh validation after recovery changes.

```sh
cargo run --release -p physics-3d
cargo run --release -p physics-3d -- --smoke-frames 360 --screenshot /tmp/physics-3d.png
cargo check -p physics-3d --target wasm32-unknown-unknown
```

Drag with the left mouse button or use arrows to orbit the camera; use the wheel to zoom. Press 1 to drop a sphere, 2 to drop a box, Space to pause and R to reset. All geometry and text are generated by first-party code. The immediate renderer has no shadow-map pass.

This sandbox has no win condition. Check stacking, angular response, ball contacts, body limits, reset/pause and camera behavior. Its solver is a bounded original implementation with no joints, mesh terrain or swept box time-of-impact; see the `ferravex-physics` README rather than assuming production physics coverage.
