## Concrete behavior and bounds

`StepOutput::new()` / Default prepare both vectors once. Private storage exposes borrowed complete event/rejection slices. `clear()` discards previous lengths without dropping allocation; every accepted step replaces previous output and returns exact lengths. Rejection preserves Match (including tick, history/lives), previous output, both allocation capacities and all CombatRules state.

Every new checked call requires actual capacities at least **48 events and 16 rejections**, regardless of roster size or predicted activity. No step tries callbacks or executes a simulation to discover output size. The bound proof is fixed and explicit: for N <=16 unique actors, each actor either respawns (R, one event), fires (S, at most Shot+Hit+Killed), or does neither. A respawn cannot fire on the same tick, so R+S <=N and R+3S <=3N <=48. This includes respawned actors killed later that same tick. Each roster actor can emit at most one rejection, so rejections <=N <=16. Tests reach all48 events (16 shots/hits/kills), all16 respawns and all16 rejections on both legacy-spawn and explicit-policy retained paths. Nothing is truncated and accepted output pushes cannot grow either vector under these bounds.

Preflight order is (1) capacities, (2) full existing allocation-free `Match::state_hash()` validation, (3) for explicit policy only, the same command validation and `spawn::Prepared::new` as existing234. All complete before output clearing, capture, tick advancement or any CombatRules callback, including read-only callbacks. No speculative callbacks. StepError priority follows that order. Full state validation intentionally reuses checkpoint acceptance: arena caps/coordinates, unique IDs, all Player fields, and bounded/ordered/valid rewind history. Invalid raw roster IDs/duplicates/overflow, nonfinite players and public tick edits leaving future/stale history are rejected without repairing them. Validation hashes the full checkpoint representation and thus adds bounded validation work; this task measures allocations, not throughput.

Invalid **shot-time claims** retain existing semantics: they suppress firing, append complete ordered rejection records, and accept the tick with movement/timers and permitted respawn processing. They are not whole-step StepError failures. Frozen, auto-respawn-disabled and invalid-weapon gates still run in their original order; invalid WeaponSettings are a combat gate, not a new preflight error. First matching input/time wins on the legacy path; input sanitization and the first16 shot-time scan are unchanged. Retained legacy-spawn calls do not add input-count/duplicate rejection. Safe-spawn calls retain234's stricter command checks.

All old convenience APIs and public struct literals/exhaustive enums remain source-compatible. `RewindStep` is unchanged. Old allocating methods still permit their original unvalidated raw state behavior, including an oversized passive roster; the checked API's stricter checkpoint-valid contract applies only to the new methods. No event variant, accepted ordering, life, motor, damage, wire, replay, checkpoint or context byte changes. Legacy order follows roster order; explicit safe-spawn handling remains ascending-ID order without reordering the Vec. Policy deferral/countdown, simultaneous reservations, accepted-only life generations, rewind old-life exclusion and replay context remain234's implementation.

```rust
pub const MAX_STEP_EVENTS: usize = 3 * MAX_PLAYERS;
pub const MAX_STEP_REJECTIONS: usize = MAX_PLAYERS;

#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)]
pub struct StepCounts { pub events: usize, pub rejected_shots: usize }

#[derive(Clone, Copy, Debug, PartialEq, Eq)]

    OutputCapacity { required: StepCounts, provided: StepCounts },
    InvalidState(checkpoint::CheckpointError),
    Spawn(spawn::Error),

// StepError implements Display and std::error::Error.

#[derive(Debug)]
pub struct StepOutput { /* private retained RewindStep storage */ }
// StepOutput implements Default (full capacities).
impl StepOutput {

    pub fn with_capacity(events: usize, rejected_shots: usize) -> Self;
    pub fn events(&self) -> &[GameEvent];
    pub fn rejected_shots(&self) -> &[(u8, RewindError)];

    pub fn clear(&mut self);

    pub fn step_into(&mut self, inputs: &[(u8, InputFrame)],
        output: &mut StepOutput) -> Result<StepCounts, StepError>;

        shot_times: &[ShotTime], output: &mut StepOutput)
        -> Result<StepCounts, StepError>;

        inputs: &[(u8, InputFrame)], shot_times: &[ShotTime], rules: &mut R,

    pub fn step_with_spawn_policy_into(&mut self,
        inputs: &[(u8, InputFrame)], shot_times: &[ShotTime],
        policy: Option<&spawn::Policy>, output: &mut StepOutput)
        -> Result<StepCounts, StepError>;
    pub fn step_with_rules_and_spawn_policy_into<R: CombatRules>(&mut self,
        inputs: &[(u8, InputFrame)], shot_times: &[ShotTime], rules: &mut R,
        policy: Option<&spawn::Policy>, output: &mut StepOutput)
        -> Result<StepCounts, StepError>;
}
```
