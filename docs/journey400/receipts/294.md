## Concrete behavior and compatibility

Recognition is disabled by default (`gesture_profile() == None`). Existing Event/Control/Output/Phase/InputCode/InputError literals and exhaustive enums are unchanged. Existing handle/handle_scaled immediate button/stick/look outputs, priority, capture lifetime, duplicate-Start behavior and End-motion policy remain unchanged. Tests compare full action snapshots after every event across default legacy handling, enabled-but-untimed handling and enabled timed handling, including scaled look, stick replacement/cancel and button edge retention. There was no pre-existing gesture classifier or gesture profile default to preserve; the new profile defaults only serve explicit opt-in callers.

The explicit timed path validates profile-enabled state, finite nonnegative seconds, global monotonic order, then existing scale/position/capture capacity validation before mutation. Errors preserve captures, origin/excursion/time history, profile, action edges/motion and time watermark. The same supplied seconds domain covers all pointers, including successful uncaptured events. Equal timestamps are allowed; earlier ones reject. There is no inferred elapsed time, wall clock, OS/browser dependency, session-length cap, maximum per-event interval or implicit timestamp on legacy focus clear. Prefer seconds since the caller's session origin; f64 precision determines resolution at large absolute times.

Logical distances are finite in `0..=1e6`, with `tap_max_distance < drag_min_distance <= swipe_min_distance`; times are finite in `0..=3600` seconds. Defaults: tap 10 px / maximum 0.25 s; drag 12 px / minimum 0 s; swipe 48 px / maximum 0.5 s. Threshold tests are inclusive. Distance calculations widen supplied f32 positions and thresholds to f64 before subtraction/squaring, preserving subnormal threshold ordering and bounded-coordinate arithmetic.

Tap requires maximum radial excursion and elapsed duration within both maxima. Drag latches once maximum excursion and minimum duration both qualify; every later Move can return Drag even after returning toward the origin. Swipe is tested only on End, using final net displacement and its own maximum duration; it does not require earlier drag recognition. End precedence is Swipe, else latched/qualifying Drag, else Tap, else none. A gap between tap and drag distances and long stationary holds may produce no gesture. End uses its supplied position even with no preceding Move; legacy stick/look control behavior still only releases on End and does not add End motion. A first qualifying End can return Drag directly. A previously observed Drag can finish as Swipe. Start and Cancel never yield observations; repeated End cannot redeliver a terminal outcome.

Recognition uses only existing accepted captures and their layout index/priority. Uncaptured Start/Move/End/Cancel returns no observation. Duplicate Start replaces that pointer's old capture, start position and timestamp in place, including at full capacity; a duplicate Start outside the layout drops it. All 16 capture slots can observe independently, with the existing TouchCapacity error on a seventeenth captured pointer. All 16 authored controls are supported. Gesture origins are actual finger starts, independent of a nonfloating stick's control center and unscaled by look sensitivity.

A successfully accepted untimed event discards recognition only for its affected capture while preserving existing immediate control behavior. A later timed Move/End cannot invent its missing start. Rejected untimed events preserve recognition. A changed valid profile, including enable/disable, releases all captures and resets recognition/time history before installing it. An identical profile preserves state. Invalid profiles validate completely before mutation, including errors in the last field after earlier changed valid fields. Changed layouts and clear also drop recognition and reset time; identical/invalid layouts preserve it. The configured profile survives clear. Cancel drops only that pointer and retains the global time watermark. Timestamp-free clear is valid for focus loss.

Reset uses existing held-output release behavior; it does not call global ActionMap focus/reset, consume queued action edges or erase unrelated key/mouse/touch motion. Tests explicitly preserve unrelated key pressed/released edges and accumulated mouse delta through cancel, resize, clear and profile change. A host that wants global focus suppression must still apply its existing ActionMap policy separately. Already returned observations belong to the caller and cannot be revoked; clear caller drag presentation/buffers alongside surface reset.

Storage is inline per existing capture, plus one optional profile and watermark. No additional queue, callback engine, observer registration, transport or InputCode mapping exists. Each successful call synchronously returns zero or one observation. Consumers must inspect it immediately or retain it under their own bounded admission policy; the API has no pending output/backpressure or hidden terminal event to drain. It cannot silently overwrite undelivered internal output or deliver one End twice. Repeated qualifying Move events deliberately each yield a sample, rather than an onset-only edge.

## Exact public signatures

All new types are public directly under the already registered `ferravex_play::input::touch` module:

```text
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct GestureProfile {
    pub tap_max_distance: f32,
    pub tap_max_seconds: f64,
    pub drag_min_distance: f32,
    pub drag_min_seconds: f64,
    pub swipe_min_distance: f32,
    pub swipe_max_seconds: f64,
}
impl Default for GestureProfile { fn default() -> Self; }
impl GestureProfile {
    pub fn validate(self) -> Result<(), GestureError>;
}
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum GestureError {
    InvalidProfile, Disabled, InvalidTime, TimeWentBackwards, Input(InputError),
}
// Implements std::fmt::Display and std::error::Error (wrapped Input is source).
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum GestureKind { Tap, Drag, Swipe }
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct GestureObservation {
    pub id: u64,
    pub control: usize,
    pub kind: GestureKind,
    pub phase: Phase,
    pub origin: Vec2,
    pub position: Vec2,
    pub elapsed_seconds: f64,
}
impl TouchSurface {
    pub fn gesture_profile(&self) -> Option<GestureProfile>;
    pub fn set_gesture_profile(
        &mut self, profile: Option<GestureProfile>, map: &mut ActionMap,
    ) -> Result<(), GestureError>;
    pub fn handle_timed(
        &mut self, event: Event, seconds: f64, map: &mut ActionMap,
    ) -> Result<Option<GestureObservation>, GestureError>;
    pub fn handle_timed_scaled(
        &mut self, event: Event, seconds: f64, map: &mut ActionMap, look_scale: Vec2,
    ) -> Result<Option<GestureObservation>, GestureError>;
}
```

Existing handle, handle_scaled, clear, set_layout and all other public signatures are unchanged. New errors are separate from InputError to preserve its exhaustive matches. No wire/save/replay/export/version changes or new saved gesture settings are introduced.

Tests import this production public path; no test-only duplicate recognizer is compiled. Cargo auto-discovers the uniquely named integration test.

Headless/custom hosts can opt in per TouchSurface using the methods above. Install the same logical-coordinate layout used for drawing/hit testing, supply time in one host-owned domain and use handle_timed_scaled in place of handle_scaled **once per event**, retaining the existing look sensitivity. Inspect returned gestures for optional authored UI/game policy separately from immediate ActionMap feeds. Consume mapped actions only inside executed fixed updates, sharing the same snapshots with systems. Gesture recognition is observation, not accepted damage/scoring/feedback or a replacement replay/authoritative input stream. Do not apply both timed and untimed handlers to the same event.

Renderer adoption would require an explicitly owned supplied-time API/observation handoff and a deliberate private-surface profile setter. This task does not invent those changes, read a browser clock, map gestures to new channels or claim a game consumed the feature. Public controls/hints, web events and native/Wasm exports remain unchanged. Optional future shared docs may describe this public API; none is required to make it callable.

The following runnable first-party recipe uses the actual TouchSurface/ActionMap and actual GameSession batches. Two zero-tick frames retain a quick tap; observations are handled separately, and two catch-up updates consume its button edges only once. Later drag/swipe observations still coalesce into one ordinary button request. Issued and executed counters are separate (all scheduled work executes in this recipe). No simulated game outcome, wall time, sleep, renderer or platform input is involved. The supplied gesture domain and injected simulation elapsed are explicit caller inputs.

```rust,check crate-type=bin
use ferravex_core::session::GameSession;
use ferravex_math::{Rect, Vec2};
use ferravex_play::input::{ActionKind, ActionMap, Binding, ContextId, InputCode, touch::*};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut map = ActionMap::default();
    let jump = map.named_action_handle("jump", ActionKind::Button, ContextId::GLOBAL,
        vec![Binding::digital(InputCode::Touch(0))])?;
    let mut touch = TouchSurface::default();
    touch.set_layout(&[Control {
        region: Region::Rect(Rect::new(0., 0., 100., 100.)), output: Output::Button(0),
    }], &mut map)?;
    touch.set_gesture_profile(Some(GestureProfile::default()), &mut map)?;
    let event = |x, phase| Event { id: 1, position: Vec2::new(x, 20.), phase };
    let mut session = GameSession::try_new(64., 4, true)?;
    let (mut observed, mut issued, mut executed, mut requests) = (0_u32, 0_u32, 0_u32, 0_u32);
    for (phase, seconds) in [(Phase::Start, 0.), (Phase::End, 0.25 / 64.)] {
        if let Some(gesture) = touch.handle_timed(event(20., phase), seconds, &mut map)? {
            assert_eq!(gesture.kind, GestureKind::Tap);
            observed += 1; // Handle observation without consuming the mapped action.
        }
        let batch = session.advance_batch(0.25 / 64.);
        issued += batch.frame().steps;
        assert_eq!(batch.ticks().len(), 0);
    }
    assert!(map.peek_handle(jump)?.pressed && map.peek_handle(jump)?.released);
    let batch = session.advance_batch(2. / 64.);
    issued += batch.frame().steps;
    for tick in batch.ticks() {
        let [action] = map.consume_tick_handles([jump])?;
        executed += 1;
        assert_eq!(tick.tick, u64::from(executed));
        requests += u32::from(action.pressed); // Share this snapshot with other systems.
    }
    assert_eq!((observed, issued, executed, requests), (1, 2, 2, 1));
    for (x, phase, seconds, expected) in [
        (20., Phase::Start, 0.5, None),
        (32., Phase::Move, 0.625, Some(GestureKind::Drag)),
        (68., Phase::End, 0.75, Some(GestureKind::Swipe)),
    ] {
        let gesture = touch.handle_timed(event(x, phase), seconds, &mut map)?;
        assert_eq!(gesture.map(|g| g.kind), expected);
        observed += u32::from(gesture.is_some());
    }
    let batch = session.advance_batch(1. / 64.);
    issued += batch.frame().steps;
    for _ in batch.ticks() {
        requests += u32::from(map.consume_tick_handles([jump])?[0].pressed);
        executed += 1;
    }
    assert_eq!((observed, issued, executed, requests), (3, 3, 3, 2));
    touch.clear(&mut map); // Focus/reset requires no timestamp; also clear caller drag UI.
    assert!(touch.handle_timed(event(20., Phase::End), 0., &mut map)?.is_none());
    Ok(())
}
```
