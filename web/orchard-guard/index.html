How to play

Protect the orchard: select plots, build towers and send waves when ready. Controls shows your current bindings; How to play explains the defaults.

In the game, Shift + Escape opens this guide and moves keyboard focus here. Pause first to stop an active wave. Exit fullscreen first if it is active.

Prepare your defenses before sending the first wave. Select a numbered plot, then build or upgrade using the bottom bar. Prices appear on the game buttons; the line under each button shows its key, the upgrade's next stats or how many coins are missing. You can build during waves. Progress saves between waves when storage is available.

Every pest you stop pays coins; every pest that reaches the farmhouse eats one apple from the harvest basket and costs a heart. Clear a wave without a leak for a perfect wave, watch for lucky double-damage bonks, and finish all four waves to earn a gardener rank. Rumour says someone royal visits in wave three.

Default controls

Saved or remapped bindings can differ from this list. Open Controls, or press F2 while the game has focus, to inspect and change your current bindings.

Click a plot
Select where to build or upgrade. Plot numbers are labels, not number-key shortcuts.
1 / 2
Build a seed sling / frost hive on the selected empty plot.
U
Upgrade the selected tower when you have enough coins.
Space
Send the next wave when no wave is active.
F
Toggle 1× / 2× fast-forward. The same fixed simulation steps run twice as often.
Escape
Pause or resume after the first wave has started. Use your current Pause / menu binding if remapped.
R
Restart with a fresh harvest. Restart / Plant again clears the current checkpoint.
Tab / arrows
Move focus among available game buttons. Shift + Tab moves backward; Enter activates the focused button.

Keyboard plot selection

In narrow windows, the large Plot buttons select all eight locations with the same Tab / arrows and Enter navigation as the other game buttons. The highlighted button identifies the selected plot. The game area can be scrolled into view below this guide.

Point / select has no keyboard binding by default. In Controls, choose Point / select and assign a keyboard key; this replaces that action's mouse binding. Close Controls, use the default W/A/S/D bindings to move the cursor over a plot, then press your assigned key. If a game button has focus, reopen and close Controls to clear that focus before selecting a plot. Use your saved movement bindings if changed.

Menus and returning to the page

Controls uses Tab or up/down arrows and Enter. Escape cancels a binding capture first; press it again to close Controls. Opening Controls or Details suspends interactive play; closing them preserves a manual pause. Switching away from the browser window also suspends play.

Shift + Escape moves from the canvas to this guide without changing the game's pause state. Fullscreen can handle Escape first, so exit fullscreen before using this shortcut. Here, Tab and Shift + Tab navigate the page normally. Close How to play with Enter on its heading, then Tab into the game to return.

Details → Player tools contains the shared accessibility preferences and player tools. Gameplay and its menus are drawn on the canvas; this text guide does not provide a live screen-reader view of the board.

Orchard Guard needs canvas and WebGL2 support. Read How to play above for the game instructions and keyboard controls.
