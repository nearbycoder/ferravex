For mouse play, choose Start practice or Resume practice, then click the game view to capture the mouse.

In the game menu, Tab or arrow keys select a button; Enter activates it. To reach the page controls, release mouse capture with Escape, then press Alt+M (Option+M on Mac). This shortcut only moves focus; it does not pause play.

How to play and default controls

Strike is a tactical first-person shooter in Dockyard. Choose Start practice for a two-minute gauntlet against a five-bot dockyard crew: frag as many as you can, chase your personal best and earn a suitably silly rank. Open Multiplayer to set up a match.

These keys are defaults. Saved or remapped controls may differ. Open Controls (F2) to inspect your current keyboard, mouse and gamepad bindings or change them. Keyboard shortcuts apply while the game view is focused. Use your current Menu binding to open or close the game menu; its default is Escape. The browser still uses Escape to release mouse capture.

Keyboard and mouse defaults

  • WASD or arrow keys: move
  • Mouse: aim; left click: fire
  • Space: jump
  • R: reload
  • Hold Tab: scoreboard
  • Escape: game menu

Controls also lists tactical actions, replay controls and device settings. Details contains the shared player, display and accessibility settings.

Menus, focus and matches

Opening Controls or Details, or losing window focus, opens the game menu. Close settings, then choose Resume practice, Return to match or Return to replay as offered. In Controls, Escape cancels a pending binding capture before closing the panel.

Offline practice pauses in the menu. Multiplayer matches continue, and you remain vulnerable. Replay playback also continues in local menus/settings; use Pause replay in Controls or the replay panel to pause it. Page focus is separate from the game menu. After returning to the game, choose its start or resume action before clicking the view for mouse capture.
