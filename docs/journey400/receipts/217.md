## Concrete behavior and compatibility

- Decomposition is `normalized_rotation = swing * twist`, as orientations up to
  floating-point rounding/sign. Twist acts first about the authored local axis;
  swing takes that axis to its final direction. Both factors are normalized.
- Every finite nonzero quaternion/axis is accepted, including very large and
  subnormal inputs. Zero or any NaN/infinite component returns `None`. Quaternion
  normalization, axis normalization, projection and angle calculation retain
  `f64` intermediates so tiny ratios are not prematurely erased by `f32`.
- Signed shortest angles are radians in `[-pi, pi]`. Antipodal input signs
  produce the same decomposition. The representative has positive scalar part;
  at exactly zero scalar part, its first nonzero vector component `(x,y,z)` is
  positive. Exact twist half-turn signs follow this representative and the axis
  projection. Reversing the axis negates the angle, including exact half-turn
  ties, and retains the rotation factors. Existing slerp/rotate-towards half-turn
  policy remains unchanged.
- An exactly zero scalar and axis projection explicitly yields
  `is_singular = true`, identity twist, zero conventional angle and the full
  canonical input as swing. Twist is underdetermined in this case, not physically
  measured as zero. There is no epsilon cutoff: nearby valid inputs retain their
  twist and report `is_singular = false`. Nominal trigonometric half turns may
  have a small scalar residual and therefore be nonsingular.
- Limits are an inclusive, ordinary nonwrapped interval of finite radians,
  `-PI <= min_angle <= max_angle <= PI`. Invalid bounds or inputs return `None`
  even for a full range. Already-valid rounded angles return normalized input
  directly, retaining its sign and avoiding unnecessary recomposition. Otherwise
  right multiplication by the twist-angle correction preserves swing/aim up to
  rounding and returns a normalized quaternion. The singular fallback uses its
  conventional zero angle and applies a bound if zero lies outside the interval.
- Rounding can put the recovered twist outside a bound. Angle/factor recovery is
  ill-conditioned as swing approaches 180 degrees; underflow can cause large
  twist-angle recovery error despite an accurate pose/aim. Exact idempotence is
  not guaranteed. This is documented on the public API, not hidden by an epsilon
  singularity snap. Applications needing continuity through the singularity must
  supply their own authoring policy/history.
- Existing `Quat` fields/layout, exhaustive `EulerRot`, unchecked APIs and J200
  027 public signatures/semantics remain intact. The old private normalization
  closure was extracted to `try_normalized_components` without changing its
  arithmetic, and is shared with the new decomposition.
- Fixed arrays, scalar arithmetic and existing quaternion/vector helpers only;
  no heap collections, unbounded work, retained state, clocks, I/O or dependencies
  were added. Capacity/reset APIs are inapplicable to these stateless operations;
  invalid-input-then-valid and repeated-application regressions cover state
  independence. No allocator instrumentation or benchmark was run.
